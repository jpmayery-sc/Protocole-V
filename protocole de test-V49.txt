0. OBJECTIF
-----------
Tester si le modèle géométrique K/T/Y + D1/D2 :
 
- ne modifie pas la propagation du photon
- ne génère pas de masse effective
- ne produit pas de birefringence non observée
- reste compatible avec les contraintes CMB
- respecte les limites astrophysiques (pulsars, GRB, VLBI)
- conserve la structure de Maxwell
 
V49 est un test fondamental : si le photon casse, tout casse.
 
 
1. V49-MAXWELL — ÉQUATIONS DE MAXWELL MODIFIÉES
------------------------------------------------
 
1.1 Lagrangien effectif
-----------------------
On ajoute les couplages géométriques possibles :
 
    L_EM = -1/4 F_{μν}F^{μν}
           + α_K K F_{μν}F^{μν}
           + α_T T F_{μν} *F^{μν}
           + α_Y Y F_{μν}F^{μν}
 
avec :
- α_K, α_Y très petits (V40–V44)
- α_T ≈ 0 (symétrie V41)
 
1.2 Contraintes
---------------
- pas de masse photonique : m_γ < 10⁻¹⁸ eV
- pas de violation de gauge
- pas de terme Chern‑Simons non physique
 
Sorties :
- modified_maxwell_equations
- photon_mass_bound_ok
- gauge_invariance_ok
- verdict
 
 
2. V49-DISPERSION — DISPERSION PHOTONIQUE
-----------------------------------------
 
On teste la relation de dispersion :
 
    ω² = k² (1 + δ_geom)
 
avec δ_geom ∝ (α_K K + α_Y Y).
 
Contraintes :
- |δ_geom| < 10⁻¹⁵ (VLBI)
- pas de birefringence : |Δv| < 10⁻¹⁶
 
Sorties :
- dispersion_shift
- birefringence_shift
- dispersion_ok
- birefringence_ok
- verdict
 
 
3. V49-CMB-POLARIZATION — ROTATION DE POLARISATION
---------------------------------------------------
 
On teste la rotation géométrique :
 
    Δα = ∫ α_T T(z) dz
 
Limite Planck 2018 :
- |Δα| < 0.35°
 
Limite ACT + SPT :
- |Δα| < 0.1°
 
Sorties :
- cmb_rotation

- verdict
