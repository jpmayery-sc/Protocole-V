0. OBJECTIF
-----------
Tester si le modèle géométrique K/T/Y + D1/D2 :
 
- ne perturbe pas les masses baryoniques
- respecte les splittings QCD connus
- ne modifie pas la physique nucléaire de façon non physique
- reste compatible avec les contraintes cosmologiques (BBN, structure)
- conserve la stabilité du proton et du neutron
 
V47 est un balayage complet du secteur baryonique.
 
 
1. V47-QCD-MASSES — MASSES p, n, Λ, Σ, Ξ
----------------------------------------
 
1.1 Forme effective
-------------------
Les masses baryoniques reçoivent une correction géométrique :
 
    m_B(model) = m_B(QCD) · (1 + ε_geom)
 
où ε_geom ∝ (a_K K + a_T T).
 
1.2 Contraintes
---------------
- |ε_geom| < 0.005 pour p, n
- |ε_geom| < 0.01 pour baryons étranges
 
Sorties :
- mass_shifts
- baryon_mass_ok
- verdict
 
 
2. V47-QCD-SPLITTINGS — ÉCARTS DE MASSE
---------------------------------------
 
On teste :
 
- Δ(m_n - m_p)
- Δ(m_Λ - m_p)
- Δ(m_Σ - m_N)
- Δ(m_Ξ - m_N)
 
Forme effective :
 
    Δ(model) = Δ(QCD) (1 + ε_split)
 
Contraintes :
- |ε_split| < 0.01
 
Sorties :
- splitting_shifts
- splitting_ok
- verdict
 
 
3. V47-BETA-DECAYS — DÉSINTÉGRATION BÊTA
----------------------------------------
 
On teste l’impact géométrique sur :
 
    n → p e ν̄
 
Observable clé :
 
    τ_n(model) = τ_n(SM) (1 + ε_β)
 
Limite :
- |ε_β| < 0.005
 
Sorties :
- beta_decay_shift
- beta_decay_ok
- verdict
 
 
4. V47-NUCLEAR-BINDING — ÉNERGIE DE LIAISON NUCLÉAIRE
------------------------------------------------------
 
On teste l’impact sur :
 
- énergie de liaison du deutérium
- stabilité du He‑4
- cohérence BBN
 
Forme effective :
 
    E_bind(model) = E_bind(SM) (1 + ε_bind)
 
Limite :
- |ε_bind| < 0.01
 
Sorties :
- binding_shifts
- BBN_ok
- nuclear_ok
- verdict
