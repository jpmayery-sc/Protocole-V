1. STRUCTURE COMPLÈTE DU MODÈLE
--------------------------------
Variables fondamentales :
- K : courbure interne
- T : torsion interne
- Y : cohérence dynamique
- D1, D2 : structures multi-échelle
- z : variable d’évolution
 
Invariants :
- stabilité de signe
- convexité du potentiel
- cohérence multi-secteur
 
 
2. THÉORIE GÉOMÉTRIQUE K/T/Y
-----------------------------
Relations internes :
- K et T couplés via α_KT
- Y impose une cohérence dynamique
- structure géométrique fermée
 
Invariants géométriques :
- K², T², KT
- dérivées régulières
- absence de singularités
 
 
3. STRUCTURE MULTI-ÉCHELLE D1/D2
---------------------------------
D1 : échelle locale  
D2 : échelle globale  
 
Couplage :
    Y_D1 = f1(K, T, Y)
    Y_D2 = f2(K, T, Y)
 
Contribution au potentiel :
    V_D = β Y_D1 Y_D2
 
 
4. POTENTIELS COMPLETS
-----------------------
4.1 Potentiel géométrique :
    V_KT = α_K K² + α_T T² + α_KT K T
 
4.2 Potentiel dynamique :
    V_Y = (γ*/2)(Y – Y∞)²
    avec γ* = 1.73
 
4.3 Terme d’intrication :
    V_ent = χ₂ T (dY/dz)
 
4.4 Potentiel total :
    V_total = V_KT + V_Y + V_ent + V_D
 
 
5. ÉQUATIONS DE MOUVEMENT
--------------------------
5.1 Pour Y :
    d²Y/dz² + γ*(Y – Y∞) + χ₂ dT/dz = 0
 
5.2 Pour T :
    dT/dz + 2α_T T + α_KT K + χ₂ dY/dz = 0
 
5.3 Pour K :
    dK/dz + 2α_K K + α_KT T = 0
