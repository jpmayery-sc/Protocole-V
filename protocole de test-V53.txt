1. VARIABLES FONDAMENTALES
---------------------------
K : courbure interne
T : torsion interne
Y : cohérence dynamique
 
D1, D2 : structures multi‑échelle (spirale / auto‑similitude)
 
z : variable d’évolution (cosmologie ou RG)
 
 
2. STRUCTURES GÉOMÉTRIQUES
---------------------------
Relations internes :
 
- K et T sont couplés via α_KT
- Y impose une cohérence dynamique
- D1/D2 imposent une structure fractale / spiralée
 
Invariants :
 
- signe(K) stable
- signe(T) stable
- convexité locale du potentiel
 
 
3. POTENTIELS
--------------
3.1 Potentiel géométrique :
    V_KT = α_K K² + α_T T² + α_KT K T
 
3.2 Potentiel dynamique :
    V_Y = (γ*/2)(Y – Y∞)²
    avec γ* = 1.73
 
3.3 Terme d’intrication (V50–V52) :
    V_ent = χ₂ T (dY/dz)
 
3.4 Potentiel total :
    V_total = V_KT + V_Y + V_ent
 
 
4. ÉQUATIONS DE MOUVEMENT
--------------------------
4.1 Pour Y :
    d²Y/dz² + γ*(Y – Y∞) + χ₂ dT/dz = 0
 
4.2 Pour T :
    dT/dz + 2α_T T + α_KT K + χ₂ dY/dz = 0
 
4.3 Pour K :
    dK/dz + 2α_K K + α_KT T = 0
 
 
5. STRUCTURE MULTI‑ÉCHELLE D1/D2
---------------------------------
D1 : échelle locale
D2 : échelle globale
 
Couplage :
    Y_D1 = f1(K, T, Y)
    Y_D2 = f2(K, T, Y)
 
Contribution au potentiel :
