3.1 Ce que c’est

5) Faiblesses majeures (conceptuelles et techniques)
5.1 Définitions insuffisantes

Les objets centraux ne sont pas définis mathématiquement :

    Qu’est-ce qu’un “flux D1” (champ ? 1-forme ? fibré ? objet causal ?)
    Qu’est-ce qu’une “surface D2” (sous-variété ? défaut topologique ? soliton ?)
    Que signifie “D2 crée le temps” de manière opératoire (quelle variable temporelle, quel observateur, quelle métrique) ?

Sans définitions, on ne peut ni calculer ni falsifier de manière robuste.
5.2 Dérivation de Schwarzschild : choix ad hoc

Le passage :

    “la fonction simple satisfaisant les contraintes est F(r)=1−Rs/r”
    est un choix, pas une dérivation. Beaucoup d’autres fonctions satisfont ces contraintes (ex : 1−(Rs/r)^p, exp(−Rs/r), etc.).
    Ensuite le sqrt est introduit comme “projection” mais sans cadre géométrique rigoureux.

Pour devenir une dérivation, il faut une structure imposant l’unicité (symétrie + équations + conditions aux limites).
5.3 Confusion dimensionnelle / interprétations

    “la masse est une fréquence interne” (ω=mc²/ħ) est vrai (Compton), mais ne suffit pas à expliquer pourquoi une particule aurait cette fréquence (c’est une reformulation).
    η(v)=1−1/γ puis v=cη(v) n’est pas cohérent comme relation fonctionnelle générale : si η dépend de v via γ(v), vous imposez une équation implicite qui ne redonne pas automatiquement la cinématique SR standard.

5.4 Lois de masse : faiblesse prédictive

    Leptons : une loi quadratique ajustée sur 3 points (e, μ, τ) n’a aucune puissance prédictive (c’est une interpolation exacte). Pour être physique, il faut :
        un paramètre discret motivé,
        une contrainte externe non ajustée (prédire une nouvelle quantité).
    Quarks : forme exponentielle Γ^n est qualitative (hiérarchie), mais sans prédiction quantitative (Γ, C, ε_q non déduits).
    Neutrinos : mν,i = T ε_i introduit 4 inconnues (T + 3 εi) pour 3 masses → sous-contraint sans structure additionnelle.

5.5 α comme défaut conique : lien incomplet

L’identification Δθ=2πα est élégante, mais il manque :

    pourquoi le défaut vaut précisément α (et pas α/2, 2α, etc.),
    comment relier ce défaut à la structure de jauge U(1), à la renormalisation, aux charges, et aux amplitudes QED,
    comment traiter le fait que α “court” avec l’énergie (running) — le texte évoque une variation ultra-faible, ce qui est en tension avec le running standard mesuré (α(0)≈1/137, α(M_Z)≈1/128).

\section{Définition : construction d'un cône 2D par défaut angulaire}  
\label{sec:cone-construction}

On considère un disque euclidien 2D (coordonnées polaires $(r,\theta)$). On retire un secteur d'angle  
\begin{equation}  
\Delta\theta = 2\pi \alpha,  
\qquad \alpha \simeq \frac{1}{137}.  
\label{eq:deficit-angle}  
\end{equation}  
Puis on recolle les bords du secteur retiré. La surface obtenue est un \textbf{cône} : le défaut angulaire est concentré au sommet.

On introduit le paramètre  
\begin{equation}  
\beta = 1-\alpha,  
\label{eq:beta-def}  
\end{equation}  
qui mesure la contraction angulaire effective. Une écriture standard de la métrique conique est  
\begin{equation}  
ds^2 = dr^2 + \beta^2 r^2\, d\theta^2,  
\qquad \theta \in [0,2\pi).  
\label{eq:conical-metric}  
\end{equation}  
L'effet du défaut est entièrement encodé par $\beta$ : quand $\alpha=0$ (donc $\beta=1$), on retrouve la métrique euclidienne.

\section{Phase géométrique : invariant de phase et origine de $\alpha$}  
\label{sec:phase-invariant}

Dans une géométrie conique, la variable angulaire est modifiée : l'angle \emph{effectif} vu par une onde de phase est contracté d'un facteur $\beta$.  
On introduit une phase angulaire effective  
\begin{equation}  
\varphi(\theta) = \beta\,\theta = (1-\alpha)\,\theta.  
\label{eq:phase-effective}  
\end{equation}  
Sur un tour complet $\theta:0\to 2\pi$, la phase accumulée vaut  
\begin{equation}  
\varphi(2\pi) = 2\pi(1-\alpha),  
\label{eq:phase-2pi}  
\end{equation}  
et donc le \emph{décalage de phase} (manque de phase par rapport au cas euclidien) est  
\begin{equation}  
\Delta\varphi = 2\pi - \varphi(2\pi) = 2\pi\alpha.  
\label{eq:phase-shift}  
\end{equation}  
Ainsi, dans cette lecture, $\alpha$ est interprétée comme un \textbf{invariant géométrique local} : un défaut angulaire/phase associé à la fermeture $\Dtwo$.

\paragraph{Remarque.}  
Cette section fixe le \emph{sens} géométrique de $\alpha$ dans $\Dtwo$ : elle n'explique pas encore pourquoi la nature sélectionne numériquement $\alpha\simeq 1/137$ (cette sélection relève d'une hypothèse supplémentaire sur la structure globale de $\Omega$ et/ou sur une condition de stabilité des formes $\Dtwo$). \section{Définition : construction d'un cône 2D par défaut angulaire}  
\label{sec:cone-construction}

On considère un disque euclidien 2D (coordonnées polaires $(r,\theta)$). On retire un secteur d'angle  
\begin{equation}  
\Delta\theta = 2\pi \alpha,  
\qquad \alpha \simeq \frac{1}{137}.  
\label{eq:deficit-angle}  
\end{equation}  
Puis on recolle les bords du secteur retiré. La surface obtenue est un \textbf{cône} : le défaut angulaire est concentré au sommet.

On introduit le paramètre  
\begin{equation}  
\beta = 1-\alpha,  
\label{eq:beta-def}  
\end{equation}  
qui mesure la contraction angulaire effective. Une écriture standard de la métrique conique est  
\begin{equation}  
ds^2 = dr^2 + \beta^2 r^2\, d\theta^2,  
\qquad \theta \in [0,2\pi).  
\label{eq:conical-metric}  
\end{equation}  
L'effet du défaut est entièrement encodé par $\beta$ : quand $\alpha=0$ (donc $\beta=1$), on retrouve la métrique euclidienne.

\section{Phase géométrique : invariant de phase et origine de $\alpha$}  
\label{sec:phase-invariant}

Dans une géométrie conique, la variable angulaire est modifiée : l'angle \emph{effectif} vu par une onde de phase est contracté d'un facteur $\beta$.  
On introduit une phase angulaire effective  
\begin{equation}  
\varphi(\theta) = \beta\,\theta = (1-\alpha)\,\theta.  
\label{eq:phase-effective}  
\end{equation}  
Sur un tour complet $\theta:0\to 2\pi$, la phase accumulée vaut  
\begin{equation}  
\varphi(2\pi) = 2\pi(1-\alpha),  
\label{eq:phase-2pi}  
\end{equation}  
et donc le \emph{décalage de phase} (manque de phase par rapport au cas euclidien) est  
\begin{equation}  
\Delta\varphi = 2\pi - \varphi(2\pi) = 2\pi\alpha.  
\label{eq:phase-shift}  
\end{equation}  
Ainsi, dans cette lecture, $\alpha$ est interprétée comme un \textbf{invariant géométrique local} : un défaut angulaire/phase associé à la fermeture $\Dtwo$.

\paragraph{Remarque.}  
Cette section fixe le \emph{sens} géométrique de $\alpha$ dans $\Dtwo$ : elle n'explique pas encore pourquoi la nature sélectionne numériquement $\alpha\simeq 1/137$ (cette sélection relève d'une hypothèse supplémentaire sur la structure globale de $\Omega$ et/ou sur une condition de stabilité des formes $\Dtwo$). Ici, on établit la correspondance : \emph{si} la fermeture minimale se modélise par un cône à défaut, \emph{alors} $\alpha$ se lit comme défaut de phase.

\section{Le photon comme circulation de $\Done$ sur le cône $\Dtwo$}  
\label{sec:photon-on-cone}

Le niveau $\Done$ est interprété comme un flux portant tension et phase, sans fermeture intrinsèque. Le photon correspond à un mode où le flux $\Done$ circule librement, sans confinement volumique $\Dthree$ et sans attache $\Dzero$.

Dans le langage $\Dtwo$, on modélise ce mode comme une onde se propageant sur la surface conique. Une forme minimale d'onde séparée est  
\begin{equation}  
\Psi(r,\theta,t) = A(r)\,e^{i\left(\omega t - m\,\varphi(\theta)\right)}  
= A(r)\,e^{i\left(\omega t - m\,\beta\,\theta\right)},  
\label{eq:wave-on-cone}  
\end{equation}  
où :  
\begin{itemize}  
  \item $\omega$ est la fréquence interne (contenu énergétique) du quantum,  
  \item $m\in\mathbb{Z}$ est un nombre d'enroulement angulaire (mode),  
  \item la phase angulaire effective est $\varphi(\theta)=\beta\theta$.  
\end{itemize}

Le défaut conique se lit alors comme une \textbf{renormalisation géométrique du nombre angulaire} :  
\begin{equation}  
m_{\mathrm{eff}} = \frac{m}{\beta} = \frac{m}{1-\alpha}.  
\label{eq:m-eff}  
\end{equation}

\subsection{Deux fréquences : déclenchement et fréquence interne}  
\label{subsec:two-frequencies}

\begin{itemize}

  \item une fréquence \textbf{interne} du quantum, notée $\omega$ (celle de \eqref{eq:wave-on-cone}).  
\end{itemize}

\begin{equation}

\qquad g(t)\ \text{non nulle sur une durée }\tau \sim \Omega_{\mathrm{clk}}^{-1}.  
\label{eq:envelope-carrier}  
\end{equation}

\end{equation}

r(\theta) = r_0\,e^{k\theta},

\label{eq:log-spiral-effective}  
\end{equation}

\end{equation}

\Gamma(\theta)=X(r(\theta),\theta)

\label{eq:3d-spiral}  
\end{equation}

\label{eq:conical-metric}

L'effet du défaut est entièrement encodé par $\beta$ : quand $\alpha=0$ (donc $\beta=1$), on retrouve la métrique euclidienne.

\section{Phase géométrique : invariant de phase et origine de $\alpha$}

\label{eq:phase-2pi}

\begin{equation}
\Delta\varphi = 2\pi - \varphi(2\pi) = 2\pi\alpha.
\label{eq:phase-shift}
\end{equation}

\section{Le photon comme circulation de $\Done$ sur le cône $\Dtwo$}
\label{sec:photon-on-cone}

X(r,\theta)=\big(\beta r\cos\theta,\ \beta r\sin\theta,\ \sqrt{1-\beta^2}\,r\big).  
\label{eq:cone-embedding}  
\end{equation}

\begin{equation}  
\Gamma(\theta)=X(r(\theta),\theta)  
= \Big(\beta r(\theta)\cos\theta,\ \beta r(\theta)\sin\theta,\ \sqrt{1-\beta^2}\,r(\theta)\Big).  
\label{eq:3d-spiral}  
\end{equation}

\subsection{Torsion extrinsèque induite}  
\label{subsec:torsion}

Le défaut angulaire du cône se manifeste en 3D comme une torsion extrinsèque (au sens où l'objet 2D plongé impose une géométrie non triviale dans l'espace). Une lecture minimale, déjà utilisée dans le manuscrit, consiste à associer au défaut un profil de torsion effectif  
\begin{equation}  
\tau(r) \sim \frac{\Delta\theta}{2\pi r} = \frac{\alpha}{r}.  
\label{eq:torsion-1-over-r}  
\end{equation}  
En identifiant un champ magnétique effectif à cette torsion (à un facteur géométrique près) :  
\begin{equation}  
B(r)=k_B\,\tau(r)\ \sim\ k_B\,\frac{\alpha}{r},  
\label{eq:B-from-torsion}  
\end{equation}  
on obtient naturellement un comportement $1/r$ analogue à celui d'un vortex/courant, ce qui fournit une passerelle opérationnelle entre la géométrie $\Dtwo$ et des signatures électromagnétiques en $\Dthree$.

\subsection{Vérification numérique : constance de $r\,\tau(r)$}  
\label{subsec:torsion-numerics}

La loi \eqref{eq:torsion-1-over-r} implique immédiatement :  
\begin{equation}  
r\,\tau(r) = \alpha \quad (\text{constante}).  
\end{equation}  
Un test numérique simple confirme que, sur un intervalle $r\in[1,50]$, on obtient bien :

\end{equation}

def delta_phi(B, L, Kphi=1.0):

import numpy as np  
import matplotlib.pyplot as plt

# -----------------------------  
# Loi du tube : omega_tube(m) = K * sqrt(m)  
# Ici m est une "masse atomique" en unités u (63.5 pour Cu, etc.)  
# K est une constante d'échelle (normalisée). Par défaut K=1 (comme ton doc).  
# -----------------------------  
def omega_tube(m, K=1.0):  
    return K * np.sqrt(m)

# -----------------------------  
# Omega_torsion = beta * n_torsions  
# Dans ton doc : beta=1, n_torsions=3 dans l'exemple  
# -----------------------------  
def omega_torsion(n_torsions, beta=1.0):  
    return beta * n_torsions

# -----------------------------  
# Fenêtres  
# F(x) = x^2 / (1 + x^2), x = omega / Omega_torsion  
# G(y) = y / (1 + y),     y = omega_tube / Omega_torsion  
# -----------------------------  
def F_activation(omega, Omega_t, eps=1e-30):  
    x = omega / (Omega_t + eps)  
    return (x**2) / (1 + x**2)

def G_resonance(m, Omega_t, K=1.0, eps=1e-30):  
    y = omega_tube(m, K=K) / (Omega_t + eps)  
    return y / (1 + y)

# -----------------------------  
# Loi complète :  
# N_eff(m, omega) = (1 + n_torsions) * F(x) * G(y)  
# -----------------------------  
def N_eff(m, omega, n_torsions, beta=1.0, K=1.0):  
    Omega_t = omega_torsion(n_torsions, beta=beta)  
    return (1 + n_torsions) * F_activation(omega, Omega_t) * G_resonance(m, Omega_t, K=K)
