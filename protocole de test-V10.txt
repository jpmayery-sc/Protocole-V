(le prolongement naturel de V9‑CRIT)

⭐ 2. V10‑SPECTRE — Séries spectrales et corrections torsionnelles
(le prolongement naturel de V8‑LEVEL)
 
Hypothèse H10‑SPECTRE
> La torsion D2 + la porte α modifient légèrement les niveaux atomiques, donc les séries spectrales.
 
Forme opérationnelle
On prend une série de Rydberg simplifiée :
 
\[
En = -\frac{RZ}{n^2}
\]
 
Et on ajoute une correction torsionnelle :
 
\[
\Delta En^{\rm torsion} = \Delta\phi(Z) \cdot \tau(rn)
\]
 
Avec :
 
- \(rn = n^2 a0\) (proxy)  
- \(\tau(rn) = \alpha/rn\)  
- \(\Delta\phi(Z)\) = module V6‑D2
 
Tests V10‑SPECTRE
- SPEC‑1 : \(\Delta E_n^{\rm torsion}\) décroît en \(1/n^2\)  
- SPEC‑2 : amplitude dans la plage 10⁻⁶–10⁻³ eV  
- SPEC‑3 : croissance avec Z
 
Résultat attendu
- corrections faibles mais structurées  
- Fe > He > H  
- Pb/U plus sensibles

⭐ 3. V10‑RYDBERG — États de Rydberg et géométrie D2
(le prolongement naturel de V7‑GEO)
 
Hypothèse H10‑RYDBERG
> Les états très excités (n ≫ 1) amplifient les effets géométriques D2.
 
Forme opérationnelle
On définit une déviation géométrique :
 
\[
\delta rn = rn(\alpha{\rm ref}) - rn(\alpha_{\rm approx})
\]
 
Avec :
 
- \(rn = n^2 a0\)  
- \(\alpha{\rm ref}\), \(\alpha{\rm approx}\) = V5‑G
 
Tests V10‑RYDBERG
- RYD‑1 : \(\delta r_n\) croît avec n  
- RYD‑2 : \(\delta rn\) reste < 1% de rn  
- RYD‑3 : cohérence avec V7‑GEO (déviation radiale)
 
Résultat attendu

- pas de divergence  
- signature D2 mesurable pour n très grands
