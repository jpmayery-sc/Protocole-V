PROTOCOLE V90 — DYNAMIQUE TEMPS / VITESSE / INFORMATION / GEOMETRIE
 
V90 — OBJECTIF
Établir la relation complète entre :
- géométrie dynamique
- temps propre local
- vitesse d’information
- vitesse effective
- redshift observé
 
afin d’unifier les anomalies cosmologiques (Hubble tension, z≈0.46, supernovas, trous noirs non-singuliers).
 
------------------------------------------------------------
 
V90-A — HYPOTHÈSES DE BASE
 
1. La géométrie n’est pas infinie.
   Elle reste régulière même dans les zones extrêmes.
 
2. Le temps propre n’est pas universel.
   Chaque région possède un rythme d’écoulement différent.
 
3. La vitesse d’information dépend du temps propre.
   v_info = d / τ
 
4. La vitesse effective observée dépend de la géométrie + du temps propre.
 
5. Le redshift contient une composante géométrique + une composante dynamique du photon.
 
------------------------------------------------------------
 
V90-B — DÉFINITION DES QUANTITÉS
 
τ(z) : temps propre local à un redshift z
d(z) : distance géométrique effective
v_info(z) : vitesse d’information
v_eff(z) : vitesse effective observée
g(z) : facteur géométrique (courbure locale)
E(z) : énergie du photon
z : redshift observé
 
------------------------------------------------------------
 
V90-C — RELATIONS FONDAMENTALES
 
1. Temps propre ↔ géométrie
   τ(z) = τ0 * g(z)
 
2. Vitesse d’information
   v_info(z) = d(z) / τ(z)
 
3. Vitesse effective observée
   v_eff(z) = v_info(z) * f_photon(z)
 
4. Redshift total
   1 + z = g(z) * f_photon(z)
 
------------------------------------------------------------
 
V90-D — ZONE CRITIQUE (z ≈ 0.46)
 
Dans cette zone :
- g(z) change rapidement
- τ(z) ralentit
- v_info(z) diminue
- v_eff(z) augmente
- le redshift devient plus fort que prévu par ΛCDM
 
------------------------------------------------------------
 
V90-E — CONSÉQUENCES PHYSIQUES
 
1. La vitesse d’information n’est pas constante.
   Elle dépend du temps propre local.
 
2. Le redshift n’est pas purement géométrique.
   Il contient une composante dynamique du photon.
 
3. La Hubble tension devient naturelle.
   Elle vient d’un changement de τ(z) + g(z).
 
4. Les supernovas super-lumineuses deviennent cohérentes.
   Conversion gamma → visible = dynamique photon + géométrie extrême.
 
5. Les trous noirs n’ont pas besoin de singularité.
   Temps propre différent + dissipation = géométrie finie.
 
------------------------------------------------------------
 
V90-F — ÉQUATION FINALE DU MODÈLE
 
1 + z = [ d(z) / (τ0 * g(z)) ] * f_photon(z)
 
------------------------------------------------------------
 
V90-G — PROCHAINES ÉTAPES
 
- Tracer v_info(z)
- Définir g(z)
- Calibrer f_photon(z)
- Comparer V90 à ΛCDM
