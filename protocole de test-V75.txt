# COSMO‑03 — DÉMONSTRATION PAR CALCUL (CADRE)
# BBN / Lithium : cohérence et relecture dans le modèle K/T/Y + D1/D2 + V_ent
############################################################
 
0. CONTEXTE
-----------
COSMO‑03 (Table 2 du V70) concerne les abondances primordiales :
- D/H
- He
- Li
 
La situation actuelle :
- D et He sont globalement cohérents avec ΛCDM + BBN standard.
- Le lithium (Li‑7) présente une tension persistante (le “lithium problem”).
 
Objectif pour V70 :
- montrer que le modèle K/T/Y + D1/D2 + V_ent :
  1) ne casse pas la cohérence BBN existante (D, He),
  2) offre une relecture possible du lithium comme effet de condition initiale géométrique,
     plutôt que comme nécessité d’une nouvelle particule.
 
 
1. OBSERVABLES
--------------
On considère les abondances primordiales normalisées :
 
    (D/H)_obs,  (He/H)_obs,  (Li/H)_obs
 
avec leurs barres d’erreur consolidées (issues des analyses BBN standard).
 
On ne refait pas ici une BBN complète, mais on teste :
- la compatibilité du modèle avec les abondances D/H et He/H,
- la possibilité de relire Li/H comme conséquence d’un choix de branche géométrique.
 
 
2. PRÉDICTION DU MODÈLE
------------------------
Le modèle K/T/Y n’introduit pas de nouvelle particule BBN.
Il modifie :
- la géométrie effective,
- la cohérence dynamique Y,
- donc la façon dont les conditions initiales sont lues.
 
La clé de COSMO‑03 dans V70 :
- ne pas toucher aux réactions nucléaires elles‑mêmes,
- mais autoriser des conditions initiales légèrement différentes via K/T/Y et Y∞.
 
En pratique :
- on considère que les abondances BBN dépendent d’un ensemble de paramètres cosmologiques
  (taux d’expansion, densités, etc.) qui, dans ce modèle, sont reliés à K, T, Y et à leurs
  valeurs initiales.
 
 
3. PIPELINE DE CALCUL (CADRE)
------------------------------
Étape 1 — Fixer le régime BBN
    On se place dans un régime de z très élevé (z_BBN), où la dynamique K/T/Y est
    en régime quasi‑stationnaire ou lent.
 
Étape 2 — Résoudre le système K/T/Y
    On résout les équations :
 
        A_Y Y'' + γ*(Y − Y∞) + χ₂ T' = 0
        A_T T'' + 2α_T T + α_KT K − χ₂ Y' = 0
        A_K K'' + 2α_K K + α_KT T = 0
 
    en imposant des conditions initiales adaptées au régime BBN (z ≫ 1).
 
Étape 3 — En déduire les paramètres effectifs BBN
    À partir de K(z_BBN), T(z_BBN), Y(z_BBN), on reconstruit :
    - le taux d’expansion effectif H_BBN
    - les densités effectives pertinentes pour BBN
 
    On vérifie que :
    - H_BBN reste dans la bande compatible avec D/H et He/H observés.
 
Étape 4 — Explorer les branches de solutions
    On explore différentes branches de conditions initiales (K₀, T₀, Y₀, Y∞) qui :
    - gardent D/H et He/H dans la bande observée,
    - mais permettent une variation de Li/H compatible avec les observations.
 
 
4. RÉSULTATS QUALITATIFS (V70)
------------------------------
Dans V70 (Table 2, COSMO‑03), la stratégie est la suivante :
 
- Le modèle est construit pour rester neutre sur BBN :
  il ne modifie pas directement les réactions nucléaires.
- Il permet cependant de relire le problème du lithium comme :
  - un effet de condition initiale géométrique,
  - plutôt qu’une nécessité d’introduire une nouvelle particule.
 
En termes de calcul :
- il existe des branches de solutions K/T/Y qui :
  - préservent H_BBN dans la bande compatible avec D/H et He/H,
  - autorisent une légère modification des conditions initiales
    pouvant réduire Li/H sans casser le reste.
 
 
5. INTERPRÉTATION PHYSIQUE
--------------------------
1) D et He :
   - Le modèle ne change pas la physique nucléaire.
   - Il maintient un taux d’expansion compatible avec les abondances observées.
   → Cohérence BBN standard préservée.
 
2) Lithium :
   - Plutôt que d’ajouter une nouvelle particule ou une nouvelle interaction exotique,
     le modèle propose que la tension sur Li/H puisse être relue comme :
       - une différence de branche géométrique (K/T/Y),
       - une condition initiale légèrement différente,
       - sans toucher aux réactions nucléaires elles‑mêmes.
 
3) Rôle de K/T/Y :
   - K : courbure interne
   - T : torsion interne
   - Y : cohérence dynamique
   Ces trois variables permettent de paramétrer des conditions initiales cosmologiques
   plus riches que dans ΛCDM, tout en restant contrôlées.
 
 
6. DÉMONSTRATION (NIVEAU CADRE)
--------------------------------
Le modèle K/T/Y + D1/D2 + V_ent :
 
- ne modifie pas directement les réactions BBN,
- permet de conserver D/H et He/H dans la bande observée,
- offre un espace de conditions initiales géométriques dans lequel
  la tension sur Li/H peut être relue comme un effet de branche,
  plutôt que comme une anomalie exigeant une nouvelle particule.
 
En termes de démonstration calculée :
- une implémentation complète consisterait à :
  1) résoudre K/T/Y jusqu’au régime BBN,
  2) en déduire H_BBN et les paramètres cosmologiques effectifs,
  3) injecter ces paramètres dans un code BBN standard,
  4) comparer D/H, He/H, Li/H avec les observations,
  5) montrer qu’il existe des branches où :
       - D/H et He/H restent cohérents,
       - Li/H est rapproché des valeurs observées.
 
V70 pose le cadre et la cohérence de cette relecture, sans encore
implémenter le code BBN complet.
