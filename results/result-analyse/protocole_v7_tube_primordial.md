# Protocole V7 - Statut physique de la Theorie du Tube Primordial

## Finalite de V7

V7 ne cherche pas une theorie du tout.
V7 cherche a determiner:

- ce qui est deja une identite physique valide;
- ce qui est une reinterprétation geometrique coherente;
- ce qui releve encore d une hypothese speculative non testee.

Aucune promotion automatique d ensemble.

## Decoupage prealable du document

Le document contient 3 niveaux de pretention differents. Ils doivent etre evalues separement.

### Niveau I - Identites et reformulations

Faible risque.

- Compacite: Xi = GM / (R c^2)
- Relations masse-rayon
- Limites geometriques: Xi <= 1/2

Ce niveau est mathematiquement solide a priori.

### Niveau II - Reinterpretations geometriques

Testables.

- Xi = F(E) * G(E)
- Classification des astres par Xi
- Relecture geometrique de Chandrasekhar et TOV
- Lecture de GW170817 via Xi

Ce niveau est testable par coherence, redondance et non-contradiction.

### Niveau III - Hypotheses fortes

Haut risque.

- ruptures p = 2, 3, 5, 7;
- tube de Moebius cosmologique;
- CMB fractal (p environ 2.4);
- resolution JWST par temps effectif;
- constante Gamma_FRB universelle.

Ces elements exigent des tests independants stricts.

## Serie de tests V7

### TEST V7-1 - Test d identite physique

Question:

La quantite centrale Xi apporte-t-elle quelque chose de nouveau, ou n est-elle qu une reformulation canonique ?

Analyse:

Xi = GM / (R c^2) est une quantite standard:

- deja utilisee en relativite;
- borne naturelle pour les trous noirs;
- invariant sans dimension.

Verdict attendu:

- Xi est une bonne variable d organisation universelle;
- mais elle n est pas une nouvelle loi.

Conclusion locale:

Xi peut servir de socle descriptif, pas de decouverte fondamentale.

### TEST V7-2 - Decomposition Xi = F(E) * G(E)

Question:

La factorisation F(E) * G(E) est-elle structurelle ou arbitraire ?

Analyse:

- F(E) = trace des modes internes;
- G(E) = determinant des modes d interface.

Probleme cle:

- les epsilon_i ne sont pas observables independamment;
- la decomposition n est pas unique;
- aucune mesure directe de F(E) ou G(E).

Verdict attendu:

- factorisation non falsifiable en l etat;
- au mieux: schema interpretatif.

### TEST V7-3 - Classification des astres par Xi

Question:

La classification par Xi est-elle reellement predictive ?

Analyse:

Les valeurs de Xi citees concernent Terre, Soleil, WD, NS, BH.

Ce sont exactement celles induites par (M, R).

Verdict:

- classification correcte;
- mais non predictive;
- pas independante des donnees d entree.

### TEST V7-4 - Chandrasekhar, TOV, GW170817

Question:

Le formalisme Xi elimine-t-il reellement la dependance a l EOS ?

Analyse critique:

La valeur Xi environ 1/2 pour BH est une identite GR.
Dire que la nature obeit a Xi = 1/2 ne demontre pas que:

- l EOS n intervient plus;
- la dynamique exacte est predite.

Verdict attendu:

- sur-interpretation causale a rejeter;
- reformulation geometrique elegante a posteriori, oui.

### TEST V7-5 - Ruptures p = 2, 3, 5, 7

Question cle:

Ces nombres premiers sont-ils necessaires ou post hoc ?

Analyse:

- aucune derivation mathematique stricte;
- aucune demonstration d unicite;
- correspondances energie versus p non testables directement.

Verdict:

- hypothese speculative non contrainte;
- pas falsifiable en l etat.

### TEST V7-6 - CMB fractal (p environ 2.4)

Question:

Le ratio l2 / l1 environ 2.45 suffit-il a etablir une dimension fractale ?

Analyse:

- un ratio n est pas un spectre;
- pas d ajustement complet de Cl;

Verdict:

- analogie, pas demonstration.

### TEST V7-7 - FRB et constantes universelles

Question:

Gamma_FRB est-elle reellement universelle ?

Analyse:

- tres petit echantillon;
- degenerescences instrumentales possibles;
- pas de test directionnel robuste.

Verdict:

- premature;
- non etabli comme invariant universel.
