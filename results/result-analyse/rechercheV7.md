# Rapport V7 - Statut physique de la Theorie du Tube Primordial

## Finalite de V7

V7 ne cherche pas une theorie du tout.
V7 cherche a separer trois niveaux de pretention:

- identite physique valide;
- reinterprétation geometrique coherente;
- hypothese speculative non testee.

Le point central n est pas de promouvoir le Tube Primordial, mais de le classer proprement.

## Base de lecture

Le protocole de travail est fixe dans [Protocole V7 Tube Primordial](protocole_v7_tube_primordial.md).

La lecture repose sur le fait que le formalisme Xi = GM / (R c^2) est deja standard en relativite et que les affirmations fortes du document V7 n ont pas toutes le meme statut.

## Niveau I - Identites et reformulations

Verdict: supported

Lecture:

- Xi = GM / (R c^2) est une variable sans dimension standard;
- la borne Xi <= 1/2 est une reformulation geometrique connue dans le langage des trous noirs;
- les relations masse-rayon appartiennent deja au socle de lecture de la gravitation compacte.

Conclusion locale:

- le Niveau I est physiquement valide comme socle descriptif;
- il n introduit pas une nouvelle loi;
- il organise seulement des faits deja connus.

## Niveau II - Reinterpretations geometriques

Verdict: partiellement soutenu

Lecture:

- la classification des astres par Xi est coherente avec les donnees (M, R), mais elle en depend directement;
- la relecture geometrique de Chandrasekhar et de TOV est elegante, mais reste une reformulation tant qu elle ne produit pas de prediction autonome;
- la lecture de GW170817 via Xi peut etre utile comme cadre, mais elle ne suffit pas a supprimer la dependance a l EOS.

Conclusion locale:

- le Niveau II est coherent comme langage de relecture;
- il reste non autonome sur le plan predictif;
- il ne faut pas le confondre avec une nouvelle dynamique physique.

## Niveau III - Hypotheses fortes

Verdict: contradicted

Lecture:

- les ruptures p = 2, 3, 5, 7 n ont pas de derivation stricte ni d unicite demontree;
- le tube de Moebius cosmologique n est pas etabli comme necessite physique;
- le CMB fractal a partir d un ratio partiel n est pas suffisant pour conclure a une dimension fractale;
- la resolution JWST par temps effectif n est pas justifiee par un test independant strict;
- Gamma_FRB universelle reste prematuree avec un echantillon trop faible.

Conclusion locale:

- le Niveau III reste speculative;
- il n est pas falsifie positivement par un unique contre-exemple, mais il n est pas assez contraint pour etre promu;
- dans l etat actuel, il faut le classer comme hypothese non testee ou insuffisamment etayee.

## TEST V7-1 - Test d identite physique

Verdict: supported

Lecture:

- Xi est bien une variable d organisation universelle;
- elle est deja standard et ne constitue pas une nouvelle loi;
- son statut est celui d un invariant descriptif utile.

Conclusion locale:

- test passe;
- socle descriptif valide;
- pas de decouverte fondamentale.

## TEST V7-2 - Decomposition Xi = F(E) * G(E)

Verdict: contradicted

Lecture:

- la decomposition n est pas unique;
- les sous-composantes F et G ne sont pas directement observables;
- sans mesure independente, la factorisation reste interpretative et non falsifiable.

Conclusion locale:

- la factorisation n a pas le statut d une structure physique demontree;
- au mieux, c est un schema de lecture.

## TEST V7-3 - Classification des astres par Xi

Verdict: supported, mais non predictive

Lecture:

- la classification par Xi est correcte;
- cependant elle est induite par les entrees (M, R);
- elle ne donne pas une prediction independante.

Conclusion locale:

- bon outil de classement;
- pas une loi autonome.

## TEST V7-4 - Chandrasekhar, TOV, GW170817

Verdict: partiellement soutenu

Lecture:

- Xi fournit une reformulation geometrique elegante;
- en revanche, elle ne supprime pas la dependance a l EOS;
- le fait qu un regime compact puisse converger vers Xi environ 1/2 n implique pas que toute la dynamique soit remplacee par Xi.

Conclusion locale:

- sur le plan geometrique, la relecture est pertinente;
- sur le plan causal, la sur-interpretation doit etre rejetee.

## TEST V7-5 - Ruptures p = 2, 3, 5, 7

Verdict: contradicted

Lecture:

- aucun argument de necessite ne force ces ruptures;
- aucune unicite n est demontree;
- la correspondance energie-versus-p reste une hypothese ajustee apres coup.

Conclusion locale:

- statut speculative non contrainte;
- pas de base suffisante pour une loi.

## TEST V7-6 - CMB fractal

Verdict: contradicted

Lecture:

- un ratio d echelles ne suffit pas a etablir une fractalite;
- il manque le spectre complet et la confrontation de bout en bout aux donnees Planck;
- l analogie est interessante, mais pas concluante.

Conclusion locale:

- l argument CMB fractal ne tient pas comme preuve.

## TEST V7-7 - FRB et constantes universelles

Verdict: contradicted

Lecture:

- l echantillon est trop faible;
- les degenerescences instrumentales restent une explication concurrente;
- l universalite de Gamma_FRB n est pas etablie.

Conclusion locale:

- hypothese prematuree;
- pas d invariant universel demontre.

## Synthese physique

Le classement final est simple:

- Niveau I: valide comme socle descriptif;
- Niveau II: coherent comme relecture geometrique, mais pas autonome;
- Niveau III: speculative et insuffisamment testee.

Le Tube Primordial ne devient donc pas une theorie physique fondamentale.
Il sert plutot de cadre interpretatif, avec un noyau solide mais limite, et plusieurs couches haut risque non stabilisees.

## Verdict global

V7 est partiellement soutenu.

Ce qui survit:

- Xi comme variable organisatrice utile;
- les reformulations geometriques locales;
- un cadre unifiant a posteriori pour plusieurs regimes compacts.

Ce qui ne survit pas:

- le statut de theorie du tout;
- les ruptures p comme lois;
- F(E) et G(E) comme objets mesurables;
- les predictions cosmologiques fortes au stade actuel.

## Conclusion finale

La Theorie du Tube Primordial n est pas une theorie physique fondamentale.
Elle constitue:

- une metatheorie geometrique interpretative;
- un langage unifiant a posteriori;
- mais pas une theorie predictive falsifiee positivement.

Regle de cloture:

- invalider le Tube Primordial ne doit pas invalider V3-V5;
- V3-V5 restent la partie physiquement etayee;
- le Tube Primordial reste un cadre speculatif de haut niveau, pas un socle.
