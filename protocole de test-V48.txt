0. OBJECTIF
-----------
Étendre le modèle géométrique K/T/Y + D1/D2 au secteur des neutrinos lourds N_R :
 
- masses lourdes (keV → TeV)
- mélange avec les neutrinos actifs
- corrections géométriques via K/T/Y
- cohérence avec V35 (neutrinos actifs)
- cohérence cosmologique (N_eff, structure)
- stabilité et absence de canaux exotiques non physiques
 
V48 teste si le modèle reste viable quand on ajoute N_R.
 
 
1. V48-MASS-MODEL — STRUCTURE DES MASSES
-----------------------------------------
 
1.1 Forme générale
------------------
On postule une matrice de masse étendue :
 
    M_ν = [ 0      m_D
            m_D^T  M_R ]
 
avec :
- m_D = λ_i K  (hérité de V35)
- M_R = M0 + α_K K + α_T T
 
1.2 Paramètres hérités
----------------------
- λ_2, λ_3 (V35)
- K_bg_best = 1.0 (V40)
- T_bg = 0 (symétrie V41)
- M0_strong (V36)
 
Sorties :
- mass_matrix
- eigenvalues
- heavy_neutrino_masses
- mass_model_ok
- verdict
 
 
2. V48-MIXING — MATRICE DE MÉLANGE ÉTENDUE
------------------------------------------
 
On calcule la matrice PMNS étendue :
 
    U = [ U_PMNS   Θ
          Θ†       U_R ]
 
avec :
- Θ ≈ m_D M_R⁻¹
 
Contraintes :
- |Θ| < 0.1 (limite expérimentale)
- pas de violation LFU excessive
- cohérence avec V46 (tau)
 
Sorties :
- mixing_angles
- sterile_active_mixing_ok
- verdict
 
 
3. V48-STERILE-DYNAMICS — DYNAMIQUE GÉOMÉTRIQUE
-----------------------------------------------
 
Les neutrinos lourds ressentent les champs géométriques :
 
    L ⊃ N_R N_R (a_K K + a_T T + η Y)
 
Effets testés :
- variation de masse avec z
- stabilité sous RG (V45)
- absence de tachyons
- cohérence avec V44 (potentiel)
 
Sorties :
- geometric_mass_shift
- RG_stability_ok
- no_tachyon_ok
- verdict
 
 
4. V48-COSMO-CONSTRAINTS — CONTRAINTES COSMOLOGIQUES
-----------------------------------------------------
 
On teste :
 
4.1 N_eff
---------
Contribution des stériles :
 
    ΔN_eff ≈ Σ |Θ_i|² f(M_R)
 
Limite :
- ΔN_eff < 0.3
 
4.2 Σmν
-------
Doit rester compatible avec :
 
    Σmν < 0.12 eV
 
4.3 Structure (fσ8)
-------------------
Les stériles ne doivent pas casser V38d/V43.
 
Sorties :
- delta_Neff
- sum_mnu
- structure_ok
- cosmology_ok
- verdict
