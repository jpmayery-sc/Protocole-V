# V78H Source Notes

This file records the web-backed reference values used by the V78H validation.

- D/H: `arXiv:1710.11129`, Cooke et al., one percent determination of the primordial deuterium abundance.
  - Quoted value: `(D/H)_P = (2.527 +/- 0.030) x 10^-5`.
- Y_p: `arXiv:2005.12290`, Hsyu et al., PHLEK Survey.
  - Quoted value: `Y_P = 0.2436 +/- 0.0040`.
- Li7/H: broad Spite-plateau window, kept conservative for validation.
  - Working window used in the script: `1.3e-10 +/- 0.2e-10`.

The bundled JSON configuration is in [data/v78h_observations.json](data/v78h_observations.json).
