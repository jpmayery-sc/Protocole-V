# V78H Real BBN Reference CSV

This file is the concrete input for the V78H validator.

It is constructed as a literature lattice from published BBN anchor values.
There is no extrapolation: every numeric value in the CSV is a published value,
threshold, or quoted central estimate from the cited sources.

Anchors used:

- D/H observation and benchmark scale: `arXiv:1710.11129`, `arXiv:1408.6953`.
- Y_P observation and benchmark scale: `arXiv:2005.12290`, `arXiv:1408.6953`.
- Lithium observed plateau window: `arXiv:astro-ph/0510636`.
- Lithium theoretical BBN window: `arXiv:0808.2818`, `arXiv:0906.4373`, `arXiv:1405.1718`.

The CSV is stored at [data/v78h_real_bbn_reference.csv](data/v78h_real_bbn_reference.csv).
