0. OBJECTIF
-----------
Tester si les couplages géométriques (a_K, a_T, η, ξ) validés pour :
 
- le muon (V35)
- le flavour (V37)
- la cosmologie (V38–V44)
 
restent **compatibles** avec le secteur tau, c’est‑à‑dire :
 
- pas de Δa_τ absurde
- pas de violation LFU excessive
- pas de modification non physique des largeurs de désintégration
- pas de rupture multi‑échelle
 
 
1. V46-TAU-GMINUS2 — MOMENT MAGNÉTIQUE DU TAU
---------------------------------------------
 
1.1 Formule effective
---------------------
Même structure que pour le muon :
 
    Δa_τ(model) ≈ c_τ (a_K K + a_T T) (m_τ² / Λ²)
 
avec :
- m_τ = 1.777 GeV
- c_τ hérité de V35 (scaling leptonique)
 
1.2 Contraintes expérimentales
------------------------------
Limite actuelle (très lâche) :
 
    |Δa_τ| < 0.01
 
1.3 Sorties
-----------
- delta_a_tau_model
- delta_a_tau_bound_ok
- verdict
 
 
2. V46-TAU-DECAYS — DÉSINTÉGRATIONS τ → ℓ ν ν̄

- BR(τ → μ ν ν̄)
- BR(τ → e ν ν̄)
 
Forme effective :
 
    Γ_τ(model) = Γ_SM (1 + ε_geom)
 
avec ε_geom ∝ (a_K² + a_T²).
 
Contraintes :
- |ε_geom| < 0.005 (limite PDG)
 
Sorties :

- tau_decay_ok
- verdict
 
 
3. V46-TAU-LFU — TESTS LFU (W, Z)
---------------------------------
 
3.1 LFU dans les désintégrations du W
-------------------------------------
Observable :
 
    R_τ/μ^W = Γ(W → τν) / Γ(W → μν)
 
Prédiction modèle :
 
    R_τ/μ^W(model) = 1 + δ_LFU^τ
 
Limite expérimentale :
 
    |δ_LFU^τ| < 0.01
 
3.2 LFU dans Z → ττ
-------------------
Observable :
 
    R_τ/μ^Z = Γ(Z → ττ) / Γ(Z → μμ)
 
Limite :
 
    |δ_LFU^Z| < 0.005
 
Sorties :
- LFU_W_shift
- LFU_Z_shift
- LFU_ok
- verdict
