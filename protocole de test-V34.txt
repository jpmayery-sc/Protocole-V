V34 — FALSIFICATION GÉOMÉTRIQUE DES MODULES MUON g‑2 ET NEUTRINOS
Version : 0.1 (structure opérationnelle)
 
 
0. OBJECTIF DE V34
------------------
Après V33 (ansatz mathématiques), V34 vise à :
 
1. Relier les paramètres géométriques (Aµ, Bµ, λi, K0, T0, Kbg…) aux données expérimentales.
2. Tester si ces relations sont cohérentes, stables et non absurdes.
3. Falsifier agressivement chaque ansatz :
   - si un paramètre doit devenir irréaliste → rejet
   - si une contrainte solide est violée → rejet
   - si plusieurs observables ne peuvent pas être satisfaites simultanément → rejet
 
V34 ne cherche pas à “faire marcher” le modèle.
Elle cherche à voir **ce qui casse**.
 
 
1. MODULE V34-MUON — FALSIFICATION DE Δaµ(K,T)
-----------------------------------------------
 
1.1 Rappel de l’ansatz V33
--------------------------
Δaµ ≈ Aµ · K̃ + Bµ · T̃ + (termes croisés éventuels)
 
avec :
K̃ = Kloc / K0
T̃ = Tloc / T0
 
Donnée cible :
|Δaµ_exp| ~ 10^-9
 
 
1.2 Étape 1 — Contraintes directes
----------------------------------
On impose :
 
Aµ · K̃ + Bµ · T̃ ≈ 10^-9
 
Test 1 :
- Si K̃, T̃ ≪ 10^-3 → Aµ, Bµ doivent être énormes → REJET
 
Test 2 :
- Si Aµ ou Bµ doivent dépasser 10^-3 → correction trop grande → REJET
 
Test 3 :
- Si le signe de Δaµ ne peut pas être reproduit → REJET
 
 
1.3 Étape 2 — Cohérence avec les autres leptons
-----------------------------------------------
On impose que les mêmes paramètres ne détruisent pas :
 
- a_e (électron) : précision 10^-12
- a_τ (tau) : moins précis mais borné
 
Test 4 :
- Si Aµ, Bµ appliqués à l’électron donnent |Δae| > 10^-12 → REJET
 
Test 5 :
- Si le tau reçoit une correction trop grande → REJET
 
 
1.4 Étape 3 — Limite MS
------------------------
On impose :
 
lim (K̃,T̃ → 0) Δaµ → 0
 
Test 6 :
- Si l’ansatz ne s’annule pas naturellement → REJET
 
 
1.5 Verdict muon
----------------
Le module produit :
 
- muon_constraints_satisfied : true/false
- electron_safe : true/false
- tau_safe : true/false
- ms_limit_ok : true/false
- muon_verdict : supported / rejected
 
 
2. MODULE V34-NEUTRINOS — FALSIFICATION DE mν_eff(K)
-----------------------------------------------------
 
2.1 Rappel de l’ansatz V33
--------------------------
mν_i,eff² ≈ m0_i² + λ_i · Kbg
 
Δm²_ij ≈ (m0_i² - m0_j²) + (λ_i - λ_j) · Kbg
 
Données cibles :
- Δm²_sol ~ 7.4×10^-5 eV²
- Δm²_atm ~ 2.5×10^-3 eV²
- Σ mν < 1 eV
 
 
2.2 Étape 1 — Reproduction des oscillations
-------------------------------------------
Test 1 :
- Existe‑t‑il un set (λi, m0_i, Kbg) qui reproduit Δm²_sol ?
 
Test 2 :
- Existe‑t‑il un set qui reproduit Δm²_atm ?
 
Si impossible → REJET
 
 
2.3 Étape 2 — Contrainte cosmologique Σ mν < 1 eV
--------------------------------------------------
Test 3 :
- Si mν_i,eff deviennent trop grands → REJET
 
Test 4 :
- Si Kbg doit être gigantesque → REJET
 
 
2.4 Étape 3 — Cohérence interne
-------------------------------
Test 5 :
- Si λi doivent être séparés par des facteurs >10^6 → modèle instable → REJET
 
Test 6 :
- Si m0_i² doivent être négatifs → REJET
 
 
2.5 Étape 4 — Dépendance environnementale
-----------------------------------------
Test 7 :
- Si δK_env induit des variations Δm² trop grandes → REJET
 
Test 8 :
- Si δK_env doit être finement ajusté → REJET
 
 
2.6 Verdict neutrinos
---------------------
Le module produit :
 
- oscillations_ok : true/false
- cosmology_ok : true/false
- parameters_reasonable : true/false
- neutrino_verdict : supported / rejected

3.2 Critère final
-----------------
Le modèle V33 est considéré comme :
 
SUPPORTED :
- si les deux modules passent tous les tests
 
PARTIALLY SUPPORTED :
- si un module passe et l’autre échoue
 
REJECTED :
- si les deux échouent
- ou si un échoue de manière catastrophique (paramètres absurdes)
