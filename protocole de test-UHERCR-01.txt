DÉMONSTRATION CALCULÉE : UHECR-01 (RAYONS COSMIQUES ULTRA-ÉNERGÉTIQUES)
Anisotropie dipolaire > 8 EeV — Test de cohérence propagation / géométrie
===========================================================
 
ID : UHECR-01  
Domaine : Rayons cosmiques ultra‑énergétiques (UHECR)  
Observable principal :  
- anisotropie dipolaire au‑delà de 8 EeV  
- cohérence source‑propagation‑champ magnétique  
- distribution angulaire large échelle  
 
Robustesse : A  
 
Lecture standard en compétition :  
- origine extragalactique diffuse  
- champs magnétiques intergalactiques (IGMF)  
- biais de composition (protons vs noyaux)  
- distribution anisotrope des sources locales  
 
Ce que l’étude V70 cherche à tester :  
- Vérifier que le modèle géométrique K/T/Y + D1/D2 + Lent  
  **ne modifie pas la propagation des UHECR**,  
  **ne change pas les champs magnétiques**,  
  **ne crée pas de faux dipôle**,  
  et reste compatible avec l’anisotropie observée par Pierre Auger.
 
 
1. OBJECTIF UHECR-01
--------------------
Les observations Pierre Auger montrent :
 
- un dipôle significatif au‑delà de 8 EeV,  
- une direction préférentielle extragalactique,  
- une amplitude ~6 %,  
- une cohérence avec une origine diffuse plutôt qu’une source unique.
 
L’objectif UHECR‑01 est de vérifier que :
 
1) le modèle géométrique **ne modifie pas la propagation des particules** à 10¹⁹ eV,  
2) il **ne change pas les champs magnétiques** (IGMF, GMF),  
3) il **ne crée pas de biais angulaire**,  
4) il **reste compatible** avec l’anisotropie dipolaire mesurée.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 + Lent agit sur :
 
- la géométrie cosmologique,  
- la cohérence dynamique Y,  
- la structure multi‑échelle,  
- la torsion extrinsèque.
 
Mais il **n’agit pas** sur :
 
- les équations de propagation des particules chargées,  
- les champs magnétiques galactiques ou extragalactiques,  
- les interactions UHECR‑photon (GZK),  
- la composition (proton vs noyaux).
 
Hypothèse clé UHECR‑01 :  
**Le modèle est neutre sur la propagation UHECR.**
 
Donc :
 
- pas de modification du rayon de Larmor,  
- pas de changement de déflexion magnétique,  
- pas de biais directionnel,  
- pas de nouvelle interaction.
 
 
3. PARAMÉTRISATION DU TEST
--------------------------
On considère les observables :
 
- amplitude dipolaire D(E)  
- direction du dipôle  
- distribution angulaire large échelle  
- cohérence avec les catalogues de galaxies
 
Le test consiste à vérifier :
 
    ΔD_mod(E) = 0  
    Δθ_mod = 0  
    ΔP(Ω)_mod = 0  
 
c’est‑à‑dire :  
**aucune contribution du modèle à l’anisotropie UHECR.**
 
 
4. PIPELINE DE CALCUL UHECR-01
------------------------------
1) Écrire la propagation standard UHECR :  
   d p⃗ /dt = q (v⃗ × B⃗)
 
2) Vérifier que K/T/Y, D1/D2 et Lent  
   → n’introduisent aucun terme local modifiant :  
     - la charge effective,  
     - la masse,  
     - les champs B⃗,  
     - la propagation relativiste.
 
3) Vérifier que Lent = X₂ T (dY/dλ)  
   → ne couple pas aux particules chargées,  
   → ne modifie pas les champs magnétiques,  
   → ne change pas les trajectoires.
 
4) Vérifier que D1/D2 n’a aucune dépendance à l’échelle du Mpc–Gpc.
 
5) En déduire :  
   ΔD_mod(E) = 0  
   Δθ_mod = 0  
   ΔP(Ω)_mod = 0
 
6) Vérifier que le modèle ne peut pas :  
   - expliquer le dipôle,  
   - amplifier ou réduire l’anisotropie,  
   - créer un biais directionnel.
 
7) Conclure :  
   cohérence propagation‑source préservée.
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :  
- dipôle dû à la distribution anisotrope des sources extragalactiques,  
- déflexion magnétique modérée,  
- cohérence avec les catalogues de galaxies.
 
Scénario K/T/Y + D1/D2 :  
- aucune modification locale,  
- aucune interaction nouvelle,  
- aucune perturbation du dipôle,  
- neutralité totale sur les UHECR.
 
 
6. CONCLUSION DE PREUVE-MODÈLE UHECR-01
---------------------------------------
La démonstration UHECR‑01 montre que :
 
1. Le modèle géométrique n’introduit **aucune correction** à la propagation
   des rayons cosmiques ultra‑énergétiques.
 
2. Les champs magnétiques restent strictement standard.
 
3. L’anisotropie dipolaire observée > 8 EeV n’est pas modifiée.
 
4. Le modèle ne peut pas produire de faux signaux UHECR.
 
5. UHECR‑01 sert de **test de cohérence propagation‑géométrie** :  
   il garantit que le modèle n’interfère pas avec les sondes UHECR,
   un secteur extrêmement sensible.
 
Ce cas UHECR‑01 est retenu comme démonstration calculée pilote pour le
secteur rayons cosmiques dans le registre V70.
