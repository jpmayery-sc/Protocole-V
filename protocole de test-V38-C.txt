2. NOUVEL ANSATZ DYNAMIQUE (MINIMAL)
------------------------------------
On enrichit légèrement G_eff(z) :
 
    G_eff(z) = G [ 1 + η0 · Sent(Y) + η1 z + η2 z(1+z) ]
 
Pourquoi ce choix ?
- z(1+z) = terme quadratique naturel en cosmologie
- nul à z=0 → ne casse pas fσ8(z=0)
- croissance douce → pas de divergence
- un seul paramètre supplémentaire η2
 
Contraintes :
- |η0| < 0.3
- |η1| < 0.1
- |η2| < 0.05   (naturalité stricte)
 
 
3. CONDITIONS V38c
------------------
1) Croissance :
   |fσ8_eff(z) - fσ8_obs(z)| < 10 % pour z ∈ {0, 0.5, 1, 1.5}
 
2) Naturalité :
   η0, η1, η2 dans les bornes ci-dessus
 
3) Cohérence multi-échelle :
   - pas de conflit avec Sent(Y)_halo = 0.9
   - pas de conflit avec K_bg_best = 1.0
   - pas de conflit avec V37-DARK
 
4) Stabilité :
   - G_eff(z) > 0 pour z ∈ [0, 3]
