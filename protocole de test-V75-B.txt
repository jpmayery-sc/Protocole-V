# PROTOCOLE COSMO‑03 — TEST BBN À CONSTRUIRE PAR LE TESTEUR
# (K/T/Y + D1/D2 + V_ent couplé à un code BBN)
############################################################
 
Objectif :
---------
Tester si le modèle K/T/Y + D1/D2 + V_ent permet :
- de conserver D/H et He/H dans la bande observée,
- tout en réduisant Li/H vers les valeurs mesurées,
- sans introduire de nouvelle particule.
 
Tâche du testeur :
------------------
1) Implémenter un code BBN (ou utiliser un code existant, type PArthENoPE / AlterBBN).
 
2) Coupler ce code à la dynamique K/T/Y :
   - résoudre le système :
        A_Y Y'' + γ*(Y − Y∞) + χ₂ T' = 0
        A_T T'' + 2α_T T + α_KT K − χ₂ Y' = 0
        A_K K'' + 2α_K K + α_KT T = 0
     dans le régime pré‑BBN (z ≫ 1),
   - en déduire le taux d’expansion effectif H_BBN(K,T,Y),
   - fournir H_BBN et les paramètres cosmologiques effectifs au code BBN.
 
3) Construire deux scénarios :
   (a) Branche “standard” K/T/Y :
       - conditions initiales (K₀, T₀, Y₀, Y∞) choisies pour reproduire
         un H_BBN proche de ΛCDM,
       - vérifier que D/H et He/H sont compatibles avec les observations.
 
   (b) Branche “géométrique” K/T/Y :
       - explorer des variations douces de (K₀, T₀, Y₀, Y∞) et/ou χ₂,
       - en imposant :
           * D/H et He/H restent dans la bande observée,
           * Li/H est le plus proche possible des valeurs mesurées.
 
4) Télécharger les données BBN réelles (D/H, He/H, Li/H) :
   - utiliser un jeu de référence récent (compilation standard),
   - construire un χ²_BBN :
        χ²_BBN = Σ_X (X_mod − X_obs)² / σ_X²
        avec X ∈ {D/H, He/H, Li/H}.
 
5) Comparer :
   - χ²_BBN,std  (branche standard K/T/Y)
   - χ²_BBN,geo  (branche géométrique K/T/Y)
 
   et conclure sur :
   - l’existence ou non de branches où :
       * D/H et He/H restent cohérents,
       * Li/H est significativement réduit,
       * χ²_BBN,geo < χ²_BBN,std.
 
Sortie attendue :
-----------------
- Courbes ou tableaux donnant :
    * D/H_mod, He/H_mod, Li/H_mod pour les deux branches,
    * χ²_BBN,std et χ²_BBN,geo,
- Conclusion binaire :
    * “branches géométriques améliorant Li/H sans casser D/H et He/H : OUI/NON”.
 
Remarque :
----------
Ce protocole fait partie des tests proposés au valideur externe.
Le présent document (V70) pose le cadre théorique et la motivation ;
la mise en œuvre numérique détaillée du code BBN couplé à K/T/Y
est laissée à un travail ultérieur dédié.
