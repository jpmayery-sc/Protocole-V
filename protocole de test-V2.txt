Le document introduit une loi étendue du transport électrique basée sur une métrique de cohérence :

et relie cette métrique à :

⚠️ Point crucial méthodologique
Tout ce qui est narratif (Edison/Maxwell/Tesla, Monás, tube atomique) n’est pas testable directement.
Ce qui est testable numériquement, ce sont uniquement :

La qualité prédictive de K(ω)K(\omega)K(ω) sur des données réelles.
Le gain mesurable par rapport à un modèle standard (sans brique globale).
La stabilité inter‑matériaux des paramètres α′,β′,g0\alpha', \beta', g_0α′,β′,g0​.

Le protocole doit donc tester le noyau mathématique, pas le récit.

B. Protocole de test progressif (recherche contrôlée)
Le protocole est volontairement découpé en 4 étages, chacun falsifiable indépendamment.

ÉTAPE 1 — Test local pur (sans Monás, sans tube)
Hypothèse H1
La partie locale seule :

est insuffisante pour expliquer les données HF réelles.
Test

Implémenter Kloc(ω)K_{\text{loc}}(\omega)Kloc​(ω) sans correction globale.
Comparer aux données mesurées :

transitions HF,
pertes,
profondeurs de peau,

Verdict attendu

✅ résidus structurés non nuls → H1 confirmée
❌ résidus aléatoires ou nuls → document invalidé dès ici
