===========================================================
DÉMONSTRATION CALCULÉE : PART-01 (g‑2 DU MUON)
ap = (g − 2)/2 — Test de neutralité du modèle
===========================================================
 
ID : PART-01  
Domaine : Physique des particules  
Observable principal :  
- anomalie magnétique du muon ap = (g − 2)/2  
 
Robustesse : A  
 
Lecture standard en compétition :  
- calculs SM hadroniques (lattice QCD, dispersif)  
- contributions BSM (leptoquarks, Z’, SUSY, etc.)  
 
Ce que l’étude V70 cherche à tester :  
- Vérifier que le modèle géométrique K/T/Y + D1/D2 + Lent  
  **reste neutre** sur ce secteur extrêmement contraint,  
  c’est‑à‑dire :  
  → ne modifie pas les interactions électromagnétiques,  
  → ne génère pas de contribution supplémentaire à g‑2,  
  → ne contamine pas les observables hadroniques.
 
 
1. OBJECTIF PART-01
-------------------
Le secteur g‑2 du muon est l’un des plus sensibles de toute la physique des particules.  
Toute nouvelle interaction, même minuscule, peut :
 
- modifier la boucle photonique,  
- ajouter une contribution hadronique,  
- ou perturber la renormalisation QED.
 
L’objectif PART‑01 est donc **inverse** des autres tests :
 
→ **démontrer que le modèle n’a AUCUN effet mesurable sur g‑2**,  
→ et qu’il reste compatible avec les contraintes SM + lattice QCD.
 
Ce test sert de **garde‑fou méthodologique** :  
si le modèle modifiait g‑2, il serait immédiatement exclu.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 + Lent agit sur :
 
- la géométrie cosmologique,  
- la cohérence dynamique Y,  
- la structure multi‑échelle,  
- la torsion extrinsèque.
 
Mais il **n’agit pas** sur :
 
- les vertex QED,  
- les boucles photon‑muon,  
- les contributions hadroniques,  
- les constantes de couplage locales.
 
Hypothèse clé PART‑01 :  
**Le modèle est neutre sur les interactions locales du muon.**
 
Donc :
 
- pas de nouvelle particule,  
- pas de nouveau vertex,  
- pas de correction radiative,  
- pas de modification du propagateur photonique.
 
 
3. PARAMÉTRISATION DU TEST
--------------------------
Pour vérifier la neutralité, on impose :
 
- aucune modification du Lagrangien QED,  
- aucune correction au vertex μ‑γ,  
- aucune contribution de Lent aux boucles locales,  
- aucune dépendance de D1/D2 à l’échelle du GeV.
 
On calcule alors :
 
- Δaμ_mod = contribution du modèle,  
- Δaμ_SM = prédiction Standard Model,  
- Δaμ_obs = valeur expérimentale.
 
Le test consiste à vérifier :
 
    Δaμ_mod = 0  
    (à la précision expérimentale)
 
 
4. PIPELINE DE CALCUL PART-01
-----------------------------
1) Écrire le Lagrangien effectif local du muon :  
   L_QED = ψ̄ (iγ·∂ − mμ) ψ − e ψ̄ γμ ψ Aμ
 
2) Vérifier que K/T/Y, D1/D2 et Lent  
   → n’ajoutent aucun terme local de type :  
     - ψ̄ σμν ψ Fμν  
     - ψ̄ γμ ψ Aμ  
     - ψ̄ ψ φ  
     - vertex à 3 ou 4 points
 
3) Vérifier que le propagateur photonique n’est pas modifié :  
   Dμν(k) = −i gμν / k²
 
4) Vérifier que Lent = X₂ T (dY/dλ)  
   → ne dépend pas des champs QED  
   → ne couple pas au muon  
   → ne modifie pas les boucles
 
5) En déduire :  
   Δaμ_mod = 0
 
6) Comparer à la précision expérimentale (~10⁻¹⁰)  
   → cohérence totale.
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :  
- g‑2 est dominé par QED, QCD hadronique, EW.  
- toute nouvelle physique doit être extrêmement fine.
 
Scénario K/T/Y + D1/D2 :  
- aucune modification locale,  
- aucune nouvelle particule,  
- aucune correction radiative,  
- neutralité totale sur g‑2.
 
 
6. CONCLUSION DE PREUVE-MODÈLE PART-01
--------------------------------------
La démonstration PART‑01 montre que :
 
1. Le modèle K/T/Y + D1/D2 + Lent **n’introduit aucune correction**  
   au vertex électromagnétique du muon.
 
2. Le propagateur photonique reste strictement standard.
 
3. Les contributions hadroniques ne sont pas modifiées.
 
4. Le modèle est **totalement neutre** sur g‑2,  
   ce qui est indispensable pour rester compatible avec les contraintes
   expérimentales les plus strictes.
 
5. PART‑01 sert donc de **test de cohérence interne** :  
   si le modèle avait modifié g‑2, il aurait été immédiatement exclu.
 
Ce cas PART‑01 est retenu comme démonstration calculée pilote pour le
secteur particules dans le registre V70.
