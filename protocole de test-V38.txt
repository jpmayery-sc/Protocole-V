0. OBJECTIF DE V38
------------------
Tester si les échelles géométriques K/T/Y extraites en V35–V37 :
 
- K_loc_best  ~ 2×10^-4
- T_loc_best  ~ 8×10^-4
- K_bg_best   = 1.0
- Sent(Y)_halo = 0.9
 
peuvent supporter une cosmologie complète :
 
1) H(z) (taux d’expansion)
2) Λ_eff(K) (constante cosmologique effective)
3) croissance des structures (δρ/ρ)
4) cohérence avec la matière noire géométrique (Sent(Y))
 
 
1. V38-HUBBLE — TEST DE H(z)
----------------------------
 
1.1 Données cibles
------------------
On utilise les mesures standard :
 
- H0 ≈ 67–74 km/s/Mpc (tension locale vs Planck)
- H(z) BAO pour z ∈ [0.1, 2.5]
 
Cible qualitative :
- reproduire la forme générale H(z)
- permettre un léger shift (tension H0)
 
 
1.2 Ansatz géométrique
----------------------
On pose :
 
H_eff(z)^2 = H_GR(z)^2 + ΔH(K_bg(z))
 
avec :
 
K_bg(z) = K_bg_best · f(z)
 
où f(z) ∈ {1, (1+z)^α, log(1+z)} selon le scan.
 
 
1.3 Condition Hubble
--------------------
On impose :
 
|H_eff(z) - H_obs(z)| < tol_H  
avec tol_H ~ 10 %
 
Tests :
- hubble_match_ok
- alpha_natural_ok (|α| < 2)
- no_explosion_ok (pas de H_eff imaginaire)
 
 
2. V38-LAMBDA — TEST DE Λ_eff(K)
--------------------------------

----------
Λ_eff = Λ0 + ξ · K_bg

- Λ0 : constante cosmologique standard

2.2 Condition Λ
---------------
On impose :
 
ρ_Λ,eff / ρ_crit ≈ 0.68 ± 0.05
 
Tests :
- lambda_match_ok
- xi_natural_ok (|ξ| < 10)
 
 
3. V38-GROWTH — CROISSANCE DES STRUCTURES

3.3 Condition croissance

|fσ8_eff(z) - fσ8_obs(z)| < tol_growth  
avec tol_growth ~ 10 %
 
Tests :
- growth_match_ok
- eta_natural_ok
