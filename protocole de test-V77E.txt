0. OBJECTIF
-----------
Après V77D, on sait que l’électron fournit un levier réel (β_e) qui fait baisser Li_total
sans casser D/H ni Y_p, mais Li_total ne passe pas encore la fenêtre.
 
V77E cherche à :
- introduire explicitement des ÉCHANGES internes Li-7 ↔ Be-7,
- introduire une VIDANGE explicite du réservoir A=7 (destruction effective),
- tester si une combinaison “échange + vidange” permet :
  - de vider Be-7 (branche dure),
  - de remplir Li-7 juste ce qu’il faut,
  - de faire passer Li_total dans la fenêtre observationnelle.
 
V77E est un test de flux internes, pas un ajustement cosmologique.
 
 
1. HYPOTHÈSES
-------------
- Paramètres globaux fixés :
  - ε_best = -0.0069
  - δ_EM = -0.0069
  - k_G, k_T, k_n = V83
- Paramètre électronique fixé au meilleur point de V77D :
  - β_e = 1.2 (ou valeur issue de V77D)
- On part des valeurs A=7 de V77D au meilleur point :
  - Li7_base, Be7_base, Li_total_base
- On ajoute deux nouveaux degrés de liberté :
  - γ_exch = intensité d’échange interne Li-7 ↔ Be-7
  - γ_drain = intensité de vidange A=7 → plus léger (destruction effective).
 
 
2. NOUVEAUX TERMES (ÉCHANGES ET VIDANGE)
----------------------------------------
On modélise les flux internes A=7 de façon phénoménologique :
 
1) Échange interne Li-7 ↔ Be-7 (contrôlé par γ_exch)
   - représente :
     - conversions Be-7 → Li-7 (capture e–, réactions secondaires),
     - éventuelles conversions Li-7 → Be-7 (si présentes).
   - modèle jouet :
     - Be7_exch = Be7_base * (1 - γ_exch)
     - Li7_exch = Li7_base + η_exch * (Be7_base - Be7_exch)
   - η_exch ∈ [0, 1] : fraction de Be-7 convertie en Li-7 (par défaut η_exch = 1).
 
2) Vidange A=7 (contrôlée par γ_drain)
   - représente la destruction effective A=7 → He-4 + X (Li-7(p,α), Be-7(n,p), etc.).
   - modèle jouet :
     - Li7_final = Li7_exch * (1 - γ_drain)
     - Be7_final = Be7_exch * (1 - γ_drain)
 
3) Li_total_final = Li7_final + Be7_final
 
Plages de test :
- γ_exch ∈ [0.0, 1.0] (5 points)
- γ_drain ∈ [0.0, 0.5] (5 points)
 
 
3. QUESTIONS DE RECHERCHE
-------------------------
V77E doit répondre à :
 
1) Un schéma “échange + vidange” peut-il :
   - réduire fortement Be-7,
   - maintenir Li-7 dans la fenêtre,
   - faire passer Li_total dans la fenêtre ?
 
2) Existe-t-il une zone (γ_exch, γ_drain) où :
   - Li-7/H est dans la fenêtre,
   - Li_total/H est dans la fenêtre,
   - D/H et Y_p restent quasi inchangés (hérités de V77D) ?
 
3) L’équilibre interne A=7 peut-il réellement “s’inverser” :
   - Be-7 cesse d’être la branche dure dominante,
   - Li-7 devient la composante principale,
   - tout en gardant un Li_total acceptable ?
 
 
4. PIPELINE V77E
----------------
 
4.1 Grille de test
------------------
- Fixer :
  - D/H et Y_p = valeurs de V77D au meilleur β_e (on ne les recalcule pas ici, on suppose qu’ils restent stables).
  - Li7_base, Be7_base = valeurs de V77D au meilleur β_e.
- Définir les grilles :
  - γ_exch ∈ [0.0, 1.0] (par ex. [0.0, 0.25, 0.5, 0.75, 1.0])
  - γ_drain ∈ [0.0, 0.5] (par ex. [0.0, 0.125, 0.25, 0.375, 0.5])
 
Pour chaque paire (γ_exch, γ_drain) :
- calculer Li7_exch, Be7_exch,
- calculer Li7_final, Be7_final,
- calculer Li_total_final,
- enregistrer les valeurs.
 
 
4.2 Critères de passage
-----------------------
Définir des fenêtres observationnelles (mêmes que V77/V80) :
 
- Li-7/H_obs ∈ [Li7_min, Li7_max]
- Li_total/H_obs ∈ [LiTot_min, LiTot_max]
 
Pour chaque (γ_exch, γ_drain) :
- marquer :
  - Li7_pass = (Li7_final dans la fenêtre Li-7)
  - LiTot_pass = (Li_total_final dans la fenêtre Li_total)
 
Identifier :
- les points où Li7_pass = True et LiTot_pass = True.
 
 
4.3 Analyse des flux
--------------------
Pour les points intéressants (Li7_pass & LiTot_pass) :
- comparer :
  - Be7_final vs Be7_base
  - Li7_final vs Li7_base
  - Li_total_final vs Li_total_base
- vérifier que :
  - Be-7 a bien été “vidé”,
  - Li-7 n’a pas été trop écrasé,
  - Li_total a réellement baissé.
 
Optionnel :
- tracer des cartes 2D :
  - Li7_final(γ_exch, γ_drain)
  - Be7_final(γ_exch, γ_drain)
  - Li_total_final(γ_exch, γ_drain)
  - masque de passage (Li7 & Li_total).

6. TRANSITION
-------------
- Si V77E trouve une zone (γ_exch, γ_drain) physiquement plausible où Li7 et Li_total passent :
  → V78R pourra tenter de relier ces paramètres à des mécanismes physiques concrets
     (réactions de destruction A=7, cinétique de capture e–, etc.).
