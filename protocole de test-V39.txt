2. V39-LIKELIHOODS — VRAISEMBLANCES PAR SECTEUR
-----------------------------------------------
 
2.1 Muon (EW)
-------------
L_mu = exp( - (Δa_mu_model - Δa_mu_exp)^2 / (2 σ_mu^2) )
 
2.2 Neutrinos
-------------
L_nu = exp( - χ²(Δm²_sol, Δm²_atm, Σmν) / 2 )
 
2.3 QCD (glueball)
------------------
L_QCD = exp( - (m_glueball_eff - 1.6)^2 / (2 σ_QCD^2) )
 
2.4 Flavour (B → K ℓℓ)
----------------------
L_flavour = exp( - (δ_RK_model - δ_RK_exp)^2 / (2 σ_flavour^2) )
 
2.5 Matière noire géométrique
-----------------------------
L_DM = exp( - (ρ_DM_eff/ρ_baryon - 5)^2 / (2 σ_DM^2) )
 
2.6 Hubble
----------
L_H = exp( - χ²_H(z) / 2 )
 
2.7 Lambda_eff
--------------
L_Lambda = exp( - (ρ_Lambda_eff/ρ_crit - 0.68)^2 / (2 σ_Lambda^2) )
 
2.8 Croissance fσ8 (dynamique D1/D2)
------------------------------------
L_growth = exp( - χ²_growth(z=0,0.5,1,1.5) / 2 )
 
 
2.9 Likelihood globale
----------------------
L_total = L_mu · L_nu · L_QCD · L_flavour · L_DM · L_H · L_Lambda · L_growth
 
 
3. V39-MCMC — CHAÎNES DE MARKOV
-------------------------------
 
3.1 Méthode
-----------
- Metropolis-Hastings
- 4 chaînes indépendantes
- 50 000 steps par chaîne
- burn-in : 10 000 steps
- thinning : 10
 
3.2 Critères de convergence
---------------------------
- Gelman-Rubin R_hat < 1.05
- autocorrélation < 0.3
- effective sample size > 500

6. CRITÈRES DE VERDICT
----------------------
 
supported :
- région non vide avec L_total > 0.1 L_max
- tensions résiduelles < 2σ
- convergence_ok = true
 
partially_supported :
- région existante mais tensions > 2σ dans un secteur
 
rejected :
- aucune région cohérente
- ou divergence structurelle D1/D2
