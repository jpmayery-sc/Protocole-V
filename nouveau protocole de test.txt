Ω₁ — Torsion intégrée du trajet (géométrie différentielle)
Définition mathématique
Pour un trajet paramétré r(s)\mathbf{r}(s)r(s) :
Ω1  =  ∫0Lτ(s) ds\boxed{
\Omega_1 \;=\; \int_0^L \tau(s)\,\mathrm{d}s
}Ω1​=∫0L​τ(s)ds​
où :

τ(s)\tau(s)τ(s) = torsion locale (repère de Frenet–Serret)
sss = abscisse curviligne
LLL = longueur totale du trajet

Sens physique minimal

mesure l’enroulement réel du trajet, indépendamment de la longueur
nul pour un trajet plan
non nul pour hélices, boucles 3D, fibres torsadées

Implémentation numérique (pseudo‑Python)

def omega_torsion(r):
    # r: array shape (N, 3) positions along path
    dr = derivative(r)
    d2r = derivative(dr)
    d3r = derivative(d2r)

    T = dr / norm(dr)
    N = derivative(T)
    N = N / norm(N)
    B = cross(T, N)

    tau = dot(derivative(B), N)
    ds = path_increment(r)

    return sum(tau * ds)

géométriquement propre et canonique
invariant par reparamétrisation
directement lié au langage des tubes

# Tube-Theory Numeric Test

## Objective

This repository implements a **strict numerical falsification test**
for the *Tube Theory* using **existing published datasets only**.

The goal is not to confirm the theory, but to determine whether it
introduces a **measurable geometric contribution** that improves
existing models **beyond known physics**.

---

## Scientific Principle

Two models are compared on identical datasets:

### Model A — Reference
- standard physics (Maxwell, QM, classical geometry)
- all known corrections allowed
- no tube contribution

### Model B — Tube Extension
Adds a single geometric term:

φ_total = φ_standard + λ · Ω

Where:
- Ω is a **fixed geometric invariant**
- λ is a **single global coefficient**
- λ is fitted **once**, then frozen

If Model B does **not** outperform Model A robustly,
the Tube Theory is **invalidated** as a physical theory.

## Definition of Ω

Only **one Ω definition** must be used per run.

Available implementations:
- `omega_winding.py`  → Ω₂ (recommended first)
- `omega_torsion.py`  → Ω₁
- `omega_deviation.py`→ Ω₃

Mixing Ω definitions is **forbidden**.

---

## Protocol

### Step 1 — Standard residuals
For each dataset:
- compute theoretical prediction
- extract residuals:
  r = data − model_standard

### Step 2 — Fit λ
- choose **one dataset only**
- fit λ in:
  model_tube = model_standard + λ · Ω
- freeze λ

### Step 3 — Cross‑dataset test
Using the same λ:
- recompute residuals on other datasets
- compare metrics:
  - RMSE
  - reduced χ²
  - AIC / BIC

---

## Validation Criteria

The Tube Theory is **provisionally supported** if:

- RMSE reduced ≥ 20%
- improvement visible on ≥ 2 independent datasets
- same λ used everywhere
- AIC/BIC favorable

Otherwise → **invalidated**.

---

## Forbidden Practices

The following automatically invalidate the test:
- dataset‑specific λ
- Ω tuned per dataset
- a posteriori parameter adjustment
- exclusion of data points post‑fit

---

## Expected Output

The `report/verdict.md` file must contain:

1. chosen Ω definition
2. fitted λ value
3. before/after metrics table
4. final binary verdict:
   - SUPPORTED
   - INVALIDATED

No interpretative text beyond this is required.

---

## Guiding Rule

> If no irreducible numeric gain survives cross‑validation,
> the Tube Theory must be abandoned as a physical theory.
