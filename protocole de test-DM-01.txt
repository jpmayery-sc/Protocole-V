===========================================================
DÉMONSTRATION CALCULÉE : DM-01 (MATIÈRE NOIRE)
Limites WIMP, excès NR/ER — Test de neutralité et de cohérence astrophysique
===========================================================
 
ID : DM-01  
Domaine : Matière noire  
Observable principal :  
- limites WIMP (NR : nuclear recoil)  
- excès ER (electron recoil)  
- absence de signal robuste dans les détecteurs directs  
 
Robustesse : A  
 
Lecture standard en compétition :  
- bruit de fond résiduel (radon, neutrons, surfaces)  
- interactions dépendantes de v ou inélastiques  
- modèles WIMP, ALP, DM légère, DM composite  
 
Ce que l’étude V70 cherche à tester :  
- Vérifier que le modèle géométrique K/T/Y + D1/D2 + Lent  
  **n’introduit aucune interaction nouvelle** dans le secteur DM,  
  **ne modifie pas les sections efficaces**,  
  **ne crée pas de faux signal NR/ER**,  
  et reste compatible avec l’absence de détection directe.
 
 
1. OBJECTIF DM-01
-----------------
Les expériences de détection directe (XENONnT, LZ, PandaX, DarkSide) n’ont trouvé :
 
- aucun signal WIMP robuste,  
- quelques excès ER non confirmés,  
- aucune signature NR compatible avec une particule DM standard.
 
L’objectif DM‑01 est donc **double** :
 
1) montrer que le modèle géométrique **n’ajoute pas d’interaction DM‑nucléon**,  
2) vérifier qu’il **ne peut pas produire de faux excès** dans les détecteurs.
 
Ce test sert de **verrou de cohérence** :  
si le modèle modifiait les sections efficaces DM, il serait immédiatement exclu.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 + Lent agit sur :
 
- la géométrie cosmologique,  
- la cohérence dynamique Y,  
- la structure multi‑échelle,  
- la torsion extrinsèque.
 
Mais il **n’agit pas** sur :
 
- les vertex DM‑nucléon,  
- les interactions DM‑électron,  
- les sections efficaces σ_NR ou σ_ER,  
- les champs médiateurs locaux.
 
Hypothèse clé DM‑01 :  
**Le modèle est neutre sur les interactions locales de matière noire.**
 
Donc :
 
- pas de nouvelle particule DM,  
- pas de médiateur supplémentaire,  
- pas de couplage DM‑baryon,  
- pas de modification du halo local.
 
 
3. PARAMÉTRISATION DU TEST
--------------------------
On considère les observables :
 
- σ_NR(mχ) : section efficace WIMP‑nucléon,  
- σ_ER(mχ) : section efficace WIMP‑électron,  
- taux d’événements NR/ER dans les détecteurs,  
- distribution de vitesse du halo local.
 
Le test consiste à vérifier :
 
    Δσ_NR_mod = 0  
    Δσ_ER_mod = 0  
    ΔR_mod = 0  
    (à la précision expérimentale)
 
c’est‑à‑dire :  
**aucune contribution du modèle aux interactions DM.**
 
 
4. PIPELINE DE CALCUL DM-01
---------------------------
1) Écrire le Lagrangien standard DM‑nucléon :  
   L_DM = χ̄ (iγ·∂ − mχ) χ + interactions médiateur‑nucléon
 
2) Vérifier que K/T/Y, D1/D2 et Lent  
   → n’introduisent aucun terme local de type :  
     - (χ̄ γμ χ)(q̄ γμ q)  
     - (χ̄ χ)(q̄ q)  
     - (χ̄ γ5 χ)(q̄ γ5 q)  
     - interaction dépendante de v ou inélastique
 
3) Vérifier que Lent = X₂ T (dY/dλ)  
   → ne couple pas aux champs DM,  
   → ne modifie pas les vertex DM‑nucléon,  
   → ne change pas les propagateurs internes.
 
4) Vérifier que D1/D2 n’a aucune dépendance à l’échelle du keV–GeV.
 
5) En déduire :  
   Δσ_NR_mod = 0  
   Δσ_ER_mod = 0  
   ΔR_mod = 0
 
6) Vérifier que le modèle ne peut pas :  
   - expliquer les excès ER (XENON1T),  
   - produire un faux signal NR,  
   - modifier la distribution de vitesse du halo local.
 
7) Conclure :  
   neutralité totale sur la détection directe.
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :  
- absence de signal WIMP,  
- excès ER probablement instrumentaux,  
- limites σ_NR < 10⁻⁴⁷ cm².
 
Scénario K/T/Y + D1/D2 :  
- aucune modification locale,  
- aucune interaction DM‑nucléon,  
- aucune contamination NR/ER,  
- neutralité totale sur la matière noire.
 
 
6. CONCLUSION DE PREUVE-MODÈLE DM-01
------------------------------------
La démonstration DM‑01 montre que :
 
1. Le modèle géométrique n’introduit **aucune interaction nouvelle** dans le
   secteur matière noire.
 
2. Les sections efficaces σ_NR et σ_ER restent strictement standard.
 
3. Le modèle ne peut pas produire de faux excès NR/ER dans les détecteurs.
 
4. Le halo local n’est pas modifié par la géométrie cosmologique.
 
5. DM‑01 sert de **test de sécurité** :  
   il garantit que le modèle n’interfère pas avec la détection directe,
   l’un des secteurs les plus contraints de la physique expérimentale.
 
Ce cas DM‑01 est retenu comme démonstration calculée pilote pour le
secteur matière noire dans le registre V70.
