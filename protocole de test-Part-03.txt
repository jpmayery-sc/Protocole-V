===========================================================
DÉMONSTRATION CALCULÉE : PART-03 (RAYON DE CHARGE DU PROTON)
Cas témoin méthodologique — Distinction biais de mesure vs vraie anomalie
===========================================================
 
ID : PART-03  
Domaine : QED / spectroscopie  
Observable principal :  
- rayon de charge du proton rp  
- cohérence muon / électron  
 
Robustesse : A  
 
Lecture standard en compétition :  
- mesures spectroscopiques hydrogène / muonic hydrogen  
- corrections QED de très haute précision  
- biais systématiques expérimentaux  
- incertitudes sur les niveaux Lamb  
 
Ce que l’étude V70 cherche à tester :  
- Servir de **cas témoin méthodologique** :  
  → vérifier que le modèle géométrique K/T/Y + D1/D2 + Lent  
     **ne modifie pas les observables QED ultra‑précises**,  
  → distinguer clairement **biais de mesure** et **vraie anomalie**,  
  → démontrer que le modèle ne peut pas “expliquer” le puzzle du proton  
     (et ne doit surtout pas le modifier).
 
 
1. OBJECTIF PART-03
-------------------
Le “proton radius puzzle” est un cas emblématique où :
 
- les mesures électroniques donnaient rp ≈ 0.88 fm,  
- les mesures muoniques donnaient rp ≈ 0.84 fm,  
- la différence semblait indiquer une nouvelle physique,  
- mais a finalement été attribuée à des **systématiques expérimentales**.
 
L’objectif PART‑03 est donc :
 
→ **montrer que le modèle géométrique n’intervient pas du tout**  
   dans les corrections QED responsables de rp,  
→ et qu’il ne peut pas générer de différence muon/e‑.  
 
Ce test sert à valider la **neutralité locale** du modèle dans un secteur
où la précision atteint 10⁻⁵.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 + Lent agit sur :
 
- la géométrie cosmologique,  
- la cohérence dynamique Y,  
- la structure multi‑échelle,  
- la torsion extrinsèque.
 
Mais il **n’agit pas** sur :
 
- les niveaux d’énergie de l’hydrogène,  
- les corrections Lamb,  
- les vertex QED e‑p ou μ‑p,  
- les contributions radiatives locales,  
- les facteurs de forme du proton.
 
Hypothèse clé PART‑03 :  
**Le modèle est strictement neutre sur la spectroscopie atomique.**
 
 
3. PARAMÉTRISATION DU TEST
--------------------------
Le rayon de charge du proton est extrait via :
 
- spectroscopie hydrogène (transitions 1S‑2S, Lamb shift),  
- spectroscopie hydrogène muonique,  
- diffusion e‑p.
 
Le test consiste à vérifier que :
 
    Δrp_mod = 0  
    (à la précision expérimentale)
 
c’est‑à‑dire :  
**aucune contribution du modèle aux niveaux atomiques.**
 
 
4. PIPELINE DE CALCUL PART-03
-----------------------------
1) Écrire le Hamiltonien atomique standard :  
   H = p²/2m − α/r + corrections QED
 
2) Vérifier que K/T/Y, D1/D2 et Lent  
   → n’ajoutent aucun terme local de type :  
     - δV(r)  
     - correction au potentiel Coulombien  
     - modification du vertex e‑p ou μ‑p  
     - terme dépendant de la distance r
 
3) Vérifier que Lent = X₂ T (dY/dλ)  
   → ne couple pas aux champs atomiques,  
   → ne modifie pas les niveaux Lamb,  
   → ne change pas les facteurs de forme du proton.
 
4) Vérifier que D1/D2 n’a aucune dépendance à l’échelle du MeV.
 
5) En déduire :  
   Δrp_mod = 0
 
6) Conclure que le modèle ne peut pas :  
   - expliquer le puzzle du proton,  
   - ni le modifier,  
   - ni créer une différence muon/e‑.
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :  
- puzzle du proton dû à des biais de mesure,  
- résolu par des analyses plus précises.
 
Scénario K/T/Y + D1/D2 :  
- aucune modification locale,  
- aucune contribution aux niveaux atomiques,  
- neutralité totale sur rp.
 
 
6. CONCLUSION DE PREUVE-MODÈLE PART-03
--------------------------------------
La démonstration PART‑03 montre que :
 
1. Le modèle géométrique n’introduit **aucune correction** aux niveaux
   atomiques de l’hydrogène ou de l’hydrogène muonique.
 
2. Le rayon de charge du proton rp reste strictement standard.
 
3. Le modèle ne peut pas produire de différence muon/e‑,  
   ce qui est essentiel pour éviter toute contamination du puzzle du proton.
 
4. PART‑03 sert de **cas témoin méthodologique** :  
   il confirme que le modèle n’interfère pas avec les observables QED
   ultra‑précises, l’un des secteurs les plus sensibles de toute la physique.
 
Ce cas PART‑03 est retenu comme démonstration calculée pilote pour le
secteur QED dans le registre V70.
