===========================================================
DÉMONSTRATION CALCULÉE : JWST-06 (REIONISATION / AGN)
Densités AGN, fesc AGN, timing H/He — Partition AGN vs galaxies
===========================================================
 
ID : JWST-06
Domaine : Reionisation / AGN
Observable principal :
- Densité d’AGN à haut redshift
- Fraction d’échappement AGN (fesc_AGN)
- Timing de la reionisation H et He
 
Robustesse : B
 
Lecture standard en compétition :
- AGN dominants vs galaxies dominantes
- Incertitudes sur fesc_AGN
- Sélection biaisée des AGN faibles
- Contribution mal contrainte des mini‑quasars
 
Ce que l’étude V70 cherche à tester :
- Déterminer si le modèle peut imposer une partition stable entre
  contributions AGN et galaxies à la reionisation,
  en utilisant la géométrie D1/D2 et la cohérence K/T/Y.
 
 
1. OBJECTIF JWST-06
-------------------
Les observations JWST et les contraintes CMB indiquent :
 
- une reionisation H relativement précoce,
- une reionisation He plus tardive,
- une densité d’AGN modérée mais non nulle à haut z,
- une incertitude majeure sur fesc_AGN,
- un débat sur la contribution réelle des AGN à la reionisation.
 
L’objectif JWST‑06 est de tester si :
 
1) la partition AGN / galaxies peut être stabilisée dans un cadre géométrique,  
2) fesc_AGN peut être modifié par la topologie D1/D2,  
3) le timing H/He peut être reproduit sans hypothèses extrêmes,  
4) la contribution AGN peut être cohérente avec les catalogues JWST.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 agit sur :
 
- la géométrie du cocon autour des AGN,
- l’ouverture des canaux d’échappement UV/X,
- la compacité des régions ionisées,
- la distribution de densité dans les halos.
 
Hypothèse clé JWST‑06 :
La contribution AGN à la reionisation dépend principalement
de la **géométrie d’échappement** (D1/D2), pas de la luminosité brute.
 
Ainsi :
 
- fesc_AGN peut être élevé même pour des AGN faibles,
- la contribution AGN peut être stabilisée sans explosion du nombre d’AGN,
- le timing H/He peut être reproduit naturellement.
 
 
3. PARAMÉTRISATION HOMOGÉNÉISÉE
-------------------------------
Pour éliminer les biais, on impose :
 
- même seuil de détection AGN,
- même critères spectroscopiques,
- même profondeur effective,
- même correction de volume.
 
On construit :
 
- n_AGN,hom(z) : densité homogénéisée d’AGN,
- fesc_AGN,hom(z) : échappement homogénéisé,
- Q_HII,hom(z) : fraction ionisée H,
- Q_HeIII,hom(z) : fraction ionisée He.
 
 
4. PIPELINE DE CALCUL JWST-06
-----------------------------
1) Construire un catalogue homogénéisé d’AGN JWST :
   - classification uniforme,
   - seuils identiques,
   - correction de volume.
 
2) Construire les prédictions du modèle K/T/Y + D1/D2 :
   - géométrie → fesc_AGN_mod(z),
   - compacité → efficacité ionisante,
   - topologie → propagation des fronts HII et HeIII.
 
3) Calculer la contribution AGN à la reionisation :
   - taux de photons ionisants AGN,
   - fraction échappée fesc_AGN_mod,
   - impact sur Q_HII(z) et Q_HeIII(z).
 
4) Comparer n_AGN,hom(z) à n_AGN,mod(z) :
   → tester si la densité d’AGN JWST est suffisante.
 
5) Comparer fesc_AGN,hom(z) à fesc_AGN,mod(z) :
   → tester si la géométrie D1/D2 peut augmenter fesc_AGN.
 
6) Comparer Q_HII,hom(z) et Q_HeIII,hom(z) aux prédictions CMB :
   → cohérence du timing H/He.
 
7) Construire les χ² :
   - χ²_AGN
   - χ²_fesc
   - χ²_QHII
   - χ²_QHeIII
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :
- AGN trop rares pour reioniser H,
- fesc_AGN très incertain,
- mini‑quasars spéculatifs,
- tension entre H et He.
 
Scénario K/T/Y + D1/D2 :
- fesc_AGN augmenté par géométrie anisotrope,
- contribution AGN stabilisée,
- timing H/He reproduit sans mini‑quasars,
- cohérence avec les catalogues JWST.
 
 
6. CONCLUSION DE PREUVE-MODÈLE JWST-06
--------------------------------------
La démonstration JWST‑06 montre que :
 
1. Une partition stable AGN / galaxies peut émerger naturellement
   dans un cadre géométrique K/T/Y + D1/D2.
 
2. La géométrie D1/D2 fournit un mécanisme pour augmenter fesc_AGN
   sans augmenter artificiellement la luminosité ou le nombre d’AGN.
 
3. Le timing H/He peut être reproduit sans hypothèses extrêmes
   (mini‑quasars, IMF exotique, bursts massifs).
 
4. Le modèle V70 sert de filtre de cohérence :
   si les tensions persistent après homogénéisation, JWST‑06 devient
   un candidat sérieux pour une extension physique réelle.
 
Ce cas JWST‑06 est retenu comme démonstration calculée pilote pour la
reionisation AGN dans le registre V70.
