Principe général de la série
La série est exploratoire mais contrainte :

❌ pas d’ajustement global unique,
❌ pas de score “qui baisse” comme critère principal,
✅ priorité absolue à :

stabilité,
invariance,
structure relative.



Chaque test consiste à :

Construire un espace vectoriel de descripteurs physiques indépendants.
Observer la géométrie des données dans cet espace.
Vérifier si cette géométrie survit aux changements (matériau, régime, retrait d’un point).


🔢 Série de tests — étape par étape
🧪 TEST 0 — Données et périmètre (pré‑requis)
Matériaux minimum

Cu, Al, Ag, Fe
(optionnel ensuite : Au, Ni)

Régimes couverts

DC / basse fréquence (référence)
HF classique (effet peau)
HF avancée / proche saturation

Observables autorisées

conductivité effective,
profondeur de peau,
pertes,
fréquence critique observée,
indicateurs magnétiques simples (binaire : oui/non).

Aucun autre traitement à ce stade.

🧪 TEST 1 — Construction de l’espace vectoriel brut
Objectif
Former un espace de description non ajusté.
Définition du vecteur candidat (exemple initial)
Pour chaque point (matériau, fréquence) :
V=(I1=f/fcritI2=δ/δrefI3=flag magneˊtique∈{0,1}I4=σ/σDC)\mathbf{V} =
\begin{pmatrix}
I_1 = f / f_{\text{crit}} \\
I_2 = \delta / \delta_{\text{ref}} \\
I_3 = \text{flag magnétique} \in \{0,1\} \\
I_4 = \sigma / \sigma_{\text{DC}}
\end{pmatrix}V=​I1​=f/fcrit​I2​=δ/δref​I3​=flag magneˊtique∈{0,1}I4​=σ/σDC​​​
👉 Remarques :

chaque composante est mesurée, pas ajustée,
aucune combinaison linéaire à ce stade,
les normalisations sont dimensionnelles, pas statistiques.


🧪 TEST 2 — Géométrie inter‑matériaux
Question posée

Les matériaux occupent‑ils une structure stable dans l’espace V\mathbf{V}V ?

Actions

projeter les points (PCA ou simple analyse géométrique),
observer :

clusters,
alignements,
séparations par régime.



Critère de réussite

une organisation non aléatoire et répétable,
sans aucun paramètre ajusté.

❌ Si le nuage est totalement chaotique → changer les composantes, pas les pondérations.

🧪 TEST 3 — Leave‑one‑material‑out (clé)
Objectif
Tester l’invariance structurelle, pas l’ajustement.
Procédure
Pour chaque matériau MMM :

retirer tous ses points,
reconstruire la structure sur les autres,
réinjecter MMM,
observer s’il retombe naturellement dans la même géométrie.

Critère fort

✅ la place relative de MMM est cohérente,
❌ elle est aberrante ou nécessite une correction spécifique.

👉 Aucun recalage autorisé.

🧪 TEST 4 — Changement de régime
Question

La structure vectorielle est‑elle continue quand on change de régime ?

Procédure

analyser séparément :

DC / BF,
HF classique,
HF avancée,


puis superposer.

Critère

✅ même organisation générale,
✅ transitions visibles mais non chaotiques,
❌ réorganisation complète → pas d’invariant.


🧪 TEST 5 — Stabilité statistique (critère dur)
Mesures
Sur les distances inter‑matériaux dans l’espace V\mathbf{V}V :

moyenne,
écart‑type,
coefficient de variation (CV).

Test
Comparer :

avant toute normalisation,
après projection dans l’espace V\mathbf{V}V.

Critère

✅ CV diminue de façon stable,
✅ le résultat survive au leave‑one‑out,
❌ CV diminue seulement pour un matériau → rejet.


🧪 TEST 6 — Tentative de réduction scalaire (optionnelle)
⚠️ Seulement si les tests 1–5 passent.
Objectif
Voir si un scalaire dérivé hérite de l’invariance vectorielle.
Exemples :

norme pondérée,
composante principale,
projection géométrique.

Critère

le scalaire doit conserver la stabilité inter‑matériaux,
sinon → on revient au vectoriel (et c’est acceptable).


🧠 Interprétation attendue

✅ Si une structure vectorielle stable émerge :

elle est l’invariant recherché,
on peut ensuite proposer des lois effectives par projection.


❌ Si aucune structure ne survit :

il n’y a pas d’invariant simple dans ce domaine,
et la branche est raisonnablement close sans invalider tube.




📌 Instructions à donner au testeur (résumé opérationnel)
Tu peux lui transmettre ce bloc tel quel :

Mission :
Chercher une structure vectorielle stable dans les données de transport HF.
Interdictions :
– pas de fit global,
– pas de paramètre ajusté par matériau,
– pas de score comme critère principal.
Critère clé :
une géométrie des données qui survit quand on enlève un matériau, un régime ou une source.
Sorties attendues :
– plots de l’espace vectoriel,
– tests leave‑one‑material‑out,
– évolution du coefficient de variation,
– conclusion : invariant vectoriel oui / non.
