0) Objet du document

But : construire un noyau calculable et falsifiable reliant :

    un défaut conique 2D (D2) paramétré par (\alpha),
    une signature géométrique 3D (torsion extrinsèque),
    une identification opérationnelle avec un champ effectif (B),
    une prédiction de déphasage/polarisation mesurable (magnétars, lasers).

Règle : toute affirmation doit être classée comme [DEF], [DER], [HYP], [TEST].
1) Définitions et unités
1.1 [DEF] Géométrie conique D2

On modélise D2 par un cône obtenu en retirant un secteur angulaire
[
\Delta\theta = 2\pi\alpha,\qquad \alpha \approx 1/137,
]
et en recollant les bords.

La métrique conique (coordonnées polaires ((r,\theta)), (\theta\in[0,2\pi))) est :
[
ds^2 = dr^2 + \beta^2 r^2 d\theta^2,\qquad \beta = 1-\alpha.
]
1.2 [DEF] Phase géométrique sur D2

Phase angulaire effective :
[
\varphi(\theta)=\beta\theta.
]
Après un tour (\theta:0\to2\pi), le déficit de phase vaut :
[
\Delta\varphi = 2\pi - 2\pi\beta = 2\pi\alpha.
]
1.3 [DEF] Grandeurs physiques

    (B) : Tesla.
    (L) : m.
    (\Delta\phi) : rad.
    (\tau) (torsion géométrique) : dimension à préciser (voir §2.2).
    (\alpha) : sans dimension.
    (B_{\rm crit}) : champ critique QED (Schwinger) ( \simeq 4.414\times 10^9\ \mathrm{T}).

2) Passage D2 → signature 3D (torsion)
2.1 [HYP] Plongement 3D minimal

On considère un plongement standard d’un cône de paramètre (\beta) dans (\mathbb{R}^3).
(À ce stade : on utilise le plongement comme support géométrique, sans dynamique.)
2.2 [HYP] Loi de torsion extrinsèque induite

Hypothèse centrale à tester :
[
\tau(r) \propto \frac{\alpha}{r}.
]
Version normalisée (choix minimal) :
[
\tau(r)=\frac{\alpha}{r}.
]
Conséquence immédiate :
[
r,\tau(r)=\alpha=\text{constante}.
]

Remarque critique :
Il faut vérifier si (\tau) est une torsion au sens de Frenet-Serret (courbe 3D), une torsion de connexion (Cartan), ou un invariant effectif. Tant que ce n’est pas clarifié, (\tau(r)=\alpha/r) reste en [HYP].
2.3 [TEST] Test géométrique interne (sans astrophysique)

Test “purement mathématique” : sur un ensemble de points (r\in[r_{\min},r_{\max}]),
vérifier numériquement que (r\tau(r)) est constant si (\tau(r)=\alpha/r) est posé.

(OK comme sanity-check, mais ce n’est pas une validation physique.)
3) Identification opérationnelle : torsion → champ effectif (B)
3.1 [HYP] Identification linéaire

On pose une correspondance opérationnelle :
[
B(r)=k_B,\tau(r),
]
où (k_B) est un facteur d’échelle (unités : Tesla·(unité de (\tau))).

Point à verrouiller :

    donner les unités de (\tau),
    fixer (k_B) soit par une mesure, soit par une dérivation dimensionnelle.

3.2 [DER] Profil radial induit

Si (\tau(r)=\alpha/r), alors :
[
B(r)=k_B,\frac{\alpha}{r}\quad\Rightarrow\quad B(r)\propto \frac{1}{r}.
]
Prédiction qualitative : décroissance en (1/r).
3.3 [TEST] Test astrophysique “profil 1/r”

Chercher des signatures où un profil effectif (B(r)\sim 1/r) est discriminant par rapport à
un dipôle (1/r^3) (ou d’autres modèles).
Ce point est délicat car les magnétars sont dominés par des géométries de champ MHD.
Il faut donc définir un observable réellement sensible au profil (polarisation intégrée, rotation de plan, etc.).
4) Déphasage / polarisation (pont vers l’observable)
4.1 [HYP] Loi minimale de déphasage

On adopte un modèle inspiré du scaling QED (birefringence du vide) :
[
\Delta\phi ;=; K_\phi,\alpha \left(\frac{B}{B_{\rm crit}}\right)^2 L,
]
où (K_\phi) est un facteur géométrique (ordre 1) à fixer.
4.2 [DER] Remplacement (B=k_B\tau)

Avec (B=k_B\tau) et (B_{\rm crit}=k_B\tau_{\rm crit}) :
[
\Delta\phi(\tau,L)=K_\phi,\alpha\left(\frac{\tau}{\tau_{\rm crit}}\right)^2 L.
]
4.3 [HYP] Polarisation résultante (modèle simple)

Pour une lumière initialement non polarisée (ou mélange de modes) :
[
P \approx \sin^2\left(\frac{\Delta\phi}{2}\right).
]
(À préciser selon conditions initiales et intégration sur la ligne de visée.)
5) Prédictions falsifiables (à produire en nombres)

B(r) = k_B α / r   (profil 1/r).

Δφ_1/r = K_φ α (B*² R*² / B_crit²) ∫_LOS ds / r².

Δφ_1/r ∝ (B*² R*² / B_crit²) (π/b).

∫ ds / (b²+s²)³ = (3π)/(8 b^5),

\section{Axe A (magnétars) : cône D2, torsion effective et birefringence testable}

\subsection{Terminologie : deux notions de torsion}  
On distingue :  
(i) une \emph{torsion effective extrinsèque} $\tau_{\mathrm{eff}}(r)$ (scalaire, unité $1/\mathrm{m}$)  
associée au défaut conique $D2$ plongé en 3D, utilisée comme signature opérationnelle ;  
(ii) la torsion de Cartan $T^a{}_{\mu\nu}$ (tenseur) de la gravité téléparallèle.  
Dans cet axe A, seule $\tau_{\mathrm{eff}}(r)$ est utilisée.

\subsection{Hypothèse géométrique : signature $1/r$}  
On adopte comme loi effective candidate (issue du défaut angulaire $\Delta\theta=2\pi\alpha$) :  
\begin{equation}  
\tau_{\mathrm{eff}}(r)=\frac{\alpha}{r}.  
\label{eq:tau-eff}  
\end{equation}

\subsection{Identification opérationnelle : torsion $\rightarrow$ champ effectif}  
On relie $\tau_{\mathrm{eff}}$ à un champ effectif $B$ par  
\begin{equation}  
B(r)=k_B\,\tau_{\mathrm{eff}}(r).  
\label{eq:B-from-tau}  
\end{equation}  
En calibrant sur une valeur de surface $B_\ast$ au rayon $R_\ast$, on élimine $k_B$ :  
\begin{equation}  
B(R_\ast)=B_\ast  
\quad\Rightarrow\quad  
k_B=\frac{B_\ast R_\ast}{\alpha},  
\qquad  
\Rightarrow\qquad  
B(r)=B_\ast\frac{R_\ast}{r}.  
\label{eq:B-profile-1overr}  
\end{equation}

\subsection{Déphasage birefringent : forme intégrée sur la ligne de visée}  
On adopte un modèle minimal de birefringence (scaling type QED) :  
\begin{equation}  
\Delta\phi  
=  
K_\phi\,\alpha  
\int_{\mathrm{LOS}}  
\left(\frac{B(r)}{B_{\mathrm{crit}}}\right)^2  
\,ds,  
\label{eq:dphi-LOS}  
\end{equation}  
où $B_{\mathrm{crit}}\simeq 4.414\times 10^9\ \mathrm{T}$ et $K_\phi$ est un facteur  
géométrique (ordre 1) regroupant les détails de polarisation initiale, géométrie locale,  
et normalisation.

En supposant une trajectoire quasi rectiligne avec paramètre d'impact $b$ :  
\begin{equation}  
r(s)=\sqrt{b^2+s^2},  
\end{equation}  
et en utilisant $B(r)=B_\ast R_\ast/r$, on obtient :  
\begin{equation}  
\Delta\phi_{1/r}(b)  
=  
K_\phi\,\alpha  
\left(\frac{B_\ast R_\ast}{B_{\mathrm{crit}}}\right)^2  
\int_{-\infty}^{+\infty}\frac{ds}{b^2+s^2}  
=  
K_\phi\,\alpha  
\left(\frac{B_\ast R_\ast}{B_{\mathrm{crit}}}\right)^2  
\frac{\pi}{b}.  
\label{eq:dphi-1overb}  
\end{equation}

\subsection{Comparaison : profil dipolaire standard $B\propto 1/r^3$}  
Pour un champ dipolaire $B(r)=B_\ast (R_\ast/r)^3$, le même calcul donne :  
\begin{equation}  
\Delta\phi_{1/r^3}(b)  
=  
K_\phi\,\alpha  
\left(\frac{B_\ast R_\ast^3}{B_{\mathrm{crit}}}\right)^2  
\int_{-\infty}^{+\infty}\frac{ds}{(b^2+s^2)^3}  
=  
K_\phi\,\alpha  
\left(\frac{B_\ast R_\ast^3}{B_{\mathrm{crit}}}\right)^2  
\frac{3\pi}{8\,b^5}.  
\label{eq:dphi-1overb5}  
\end{equation}

\subsection{Prédiction falsifiable (forme)}  
Les deux scénarios prédisent des dépendances radicalement différentes en paramètre d'impact :  
\begin{equation}  
\Delta\phi_{1/r}(b)\propto b^{-1},  
\qquad  
\Delta\phi_{1/r^3}(b)\propto b^{-5}.  
\end{equation}  
Ainsi, toute mesure de polarisation (IXPE/eXTP) corrélée à une géométrie d'émission donnant  
accès à un proxy de $b$ peut discriminer la signature $1/r$.

\paragraph{Falsification (axe A).}  
Si les données de polarimétrie excluent une loi compatible avec $\Delta\phi\propto 1/b$ au profit  
d'une loi compatible dipolaire (ou équivalente) sur un ensemble d'objets, alors l'hypothèse  
$\tau_{\mathrm{eff}}(r)=\alpha/r$ comme contribution dominante au déphasage est falsifiée  
(ou doit être subdominante).

[HYP] Un lepton (chargé) possède une échelle de rayon R1 et une tension de surface σ (effective)  
qui stabilise l’auto-répulsion électrostatique.

[DER] Pression électrostatique (Maxwell stress) pour une charge effective sur une sphère :  
P_EM(R) = K_EM * (α ħ c) / R^4,  
où K_EM est un facteur numérique à dériver (convention).

[DER] Pression de Laplace (tension de surface) :  
ΔP_σ = 2σ/R.

[DER] Équilibre mécanique :  
2σ/R = K_EM (α ħ c)/R^4  =>  σ = (K_EM/2) (α ħ c)/R^3.

[DER] Énergie de surface :  
A ≡ σ S, avec S=4πR^2  =>  A = 2π K_EM (α ħ c)/R.

[CHECK] Si l’on paramètre aussi un terme d’échelle C lié à 1/R :  
C ≡ K_C (ħ c)/(α R),  
alors on obtient une relation structurelle :  
A = (2π K_EM / K_C) α^2 C.  
Le coefficient numérique dépend des conventions (K_EM, K_C) et doit être fixé une fois.

[AXE MASSES — Option C (cône+calotte)]  
On modélise la fermeture D3 d’un lepton comme une surface fermée composée d’une nappe conique  
(héritée de D2) et d’une calotte (cap). On introduit des facteurs géométriques d’ordre 1 :

S(R)=k_S 4π R^2  (aire effective)  
H_eff = k_H / R  (courbure moyenne effective)

Pression EM (Maxwell stress, ordre de grandeur) :  
P_EM(R)=k_P (α ħ c)/R^4, avec k_P ~ O(1) (géométrie + non-uniformité).

Pression de tension (Laplace généralisé) :  
ΔP_σ(R)=2σ H_eff = 2σ k_H/R.

Équilibre :  
P_EM = ΔP_σ  =>  σ(R)= (k_P/(2k_H)) (α ħ c)/R^3.

Énergie de surface :  
A = σ S(R) = (2π k_S k_P/k_H) (α ħ c)/R.

Conclusion : le lien structurel A ∝ (α ħ c)/R est robuste ; la géométrie (cône+cap)  
ne change que le facteur κ=(2π k_S k_P/k_H).

[C2 — Fermeture cône + calotte sphérique ajustée]  
Pour β=1−α avec α=1/137.035999..., on a θc=asin(β)=83.074°.  
La calotte sphérique ajustée au cône donne :

R_s/R = sec(θc) = 8.2927  
h/R   = sec(θc) − tan(θc) = 6.051e−2

Aires :  
S_cone/R^2 = π/β = 3.1647  
S_cap /R^2 = 2π (R_s/R)(h/R) = 3.1531  
S_tot /R^2 = 6.3178

Coefficients effectifs :  
k_S = S_tot/(4πR^2) = 0.5028  
k_H = H_eff R ≈ (S_cap/S_tot) (R/R_s) = 6.018e−2

Donc κ = 2π k_S/k_H = 5.249e1.

Conclusion : l’équilibre Laplace-Maxwell sur une fermeture cône+cap introduit un  
facteur géométrique κ ≈ 52.5 dans A = κ k_P (α ħ c)/R.  
La relation A ∝ α^2 C reste vraie, mais avec un coefficient O(10–100),  
pas O(1).

[AXE MASSES — TEST DE COHÉRENCE : équilibre électrostatique]  
On a testé la fermeture C2 (cône+calotte) donnant κ≈52.49 et l’hypothèse  
d’équilibre Maxwell–Laplace conduisant à une contrainte de type A = ξ α^2 C.

En calibrant (m0,B,C) sur (m_e,m_μ,m_τ) sous cette contrainte, on obtient systématiquement :  
- C < 0  => R1 ∝ 1/C < 0 (rayon non physique),  
- m0 ~ 2.44 GeV, A ~ -3.08 GeV (coefficients non physiques).

Conclusion : la contrainte A = ξ α^2 C (dans la loi de masse actuelle  
m(n)=m0 + A n^{2/3} + B n^2 + C (nα)^2) est incompatible avec une interprétation  
physique simple (C énergie positive) et est rejetée sous cette forme.

On conserve uniquement le scaling général P_EM ∝ 1/R^4 et A ∝ 1/R comme heuristique,  
mais sans l’identifier à C(nα)^2.
