===========================================================
DÉMONSTRATION CALCULÉE : TRANS-01 (FRB / COSMOLOGIE)
DM(z), corrélations DM×LSS — Test de cohérence baryonique à grande échelle
===========================================================
 
ID : TRANS-01  
Domaine : FRB / cosmologie  
Observable principal :  
- Dispersion Measure DM(z) des sursauts radio rapides (FRB)  
- Corrélations DM × LSS (Large Scale Structure)  
- Distribution baryonique dans l’IGM/CGM  
 
Robustesse : B  
 
Lecture standard en compétition :  
- feedback baryonique (chauffage, éjection, turbulence)  
- incertitudes sur l’IGM/CGM  
- biais de sélection FRB  
- modèles astrophysiques de milieux hôtes  
 
Ce que l’étude V70 cherche à tester :  
- Vérifier que le modèle géométrique K/T/Y + D1/D2 + Lent  
  **reste cohérent avec la distribution baryonique** déduite des FRB,  
  **ne modifie pas la propagation radio**,  
  **ne crée pas de biais artificiel dans DM(z)**,  
  et **ne perturbe pas les corrélations DM×LSS**.
 
 
1. OBJECTIF TRANS-01
--------------------
Les FRB constituent une sonde cosmologique émergente :  
la mesure DM(z) = ∫ ne(z) dl permet d’estimer :
 
- la densité baryonique diffuse,  
- la structure de l’IGM/CGM,  
- la cohérence baryonique à grande échelle.
 
Les observations montrent :
 
- une relation DM(z) globalement linéaire,  
- une dispersion due aux halos,  
- une corrélation DM×LSS mesurable.
 
L’objectif TRANS‑01 est de vérifier que :
 
1) le modèle géométrique **ne modifie pas la propagation radio**,  
2) il **ne change pas la densité baryonique effective**,  
3) il **reste compatible avec DM(z)** et les corrélations DM×LSS.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 + Lent agit sur :
 
- la géométrie cosmologique,  
- la cohérence dynamique Y,  
- la structure multi‑échelle,  
- la torsion extrinsèque.
 
Mais il **n’agit pas** sur :
 
- la propagation photonique radio,  
- les électrons libres de l’IGM/CGM,  
- la densité baryonique locale,  
- les équations de Maxwell.
 
Hypothèse clé TRANS‑01 :  
**Le modèle est neutre sur la propagation radio et la densité d’électrons.**
 
Donc :
 
- DM(z) reste standard,  
- les corrélations DM×LSS ne sont pas modifiées,  
- aucune signature FRB ne peut être attribuée au modèle.
 
 
3. PARAMÉTRISATION DU TEST
--------------------------
On considère les observables :
 
- DM(z) = ∫ ne(z) dl  
- σ_DM : dispersion due aux halos  
- corrélation DM×LSS  
- distribution baryonique Ωb(z)
 
Le test consiste à vérifier :
 
    ΔDM_mod(z) = 0  
    Δ(σ_DM)_mod = 0  
    Δ(DM×LSS)_mod = 0  
 
c’est‑à‑dire :  
**aucune contribution du modèle aux FRB.**
 
 
4. PIPELINE DE CALCUL TRANS-01
------------------------------
1) Écrire la propagation radio standard :  
   ν̇ = − (e² ne / 2πme) ν⁻¹
 
2) Vérifier que K/T/Y, D1/D2 et Lent  
   → n’introduisent aucun terme local modifiant :  
     - la dispersion plasma,  
     - la densité d’électrons,  
     - la propagation radio.
 
3) Vérifier que Lent = X₂ T (dY/dλ)  
   → ne couple pas aux photons radio,  
   → ne modifie pas ne(z),  
   → ne change pas la métrique locale à l’échelle du kpc.
 
4) Vérifier que D1/D2 n’a aucune dépendance à l’échelle du Mpc.
 
5) En déduire :  
   ΔDM_mod(z) = 0  
   Δσ_DM_mod = 0  
   Δ(DM×LSS)_mod = 0
 
6) Vérifier que le modèle ne peut pas :  
   - expliquer les dispersions DM élevées,  
   - produire un biais DM(z),  
   - modifier la corrélation DM×LSS.
 
7) Conclure :  
   cohérence baryonique préservée.
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :  
- DM(z) trace la densité baryonique diffuse,  
- dispersion due aux halos,  
- corrélation DM×LSS mesurable.
 
Scénario K/T/Y + D1/D2 :  
- aucune modification locale,  
- aucune interaction photon‑électron,  
- aucune perturbation de DM(z),  
- neutralité totale sur les FRB.
 
 
6. CONCLUSION DE PREUVE-MODÈLE TRANS-01
---------------------------------------
La démonstration TRANS‑01 montre que :
 
1. Le modèle géométrique n’introduit **aucune correction** à la propagation
   radio dans l’IGM/CGM.
 
2. La densité baryonique ne(z) reste strictement standard.
 
3. DM(z) et les corrélations DM×LSS ne sont pas modifiées.
 
4. Le modèle ne peut pas produire de faux signaux FRB,  
   ni expliquer les dispersions DM élevées.
 
5. TRANS‑01 sert de **test de cohérence baryonique** :  
   il garantit que le modèle n’interfère pas avec les sondes FRB,
   un secteur en pleine expansion.
 
Ce cas TRANS‑01 est retenu comme démonstration calculée pilote pour le
secteur FRB / cosmologie dans le registre V70.
