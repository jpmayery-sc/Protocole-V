Protocole V12
 
Vue d’ensemble
 
V12 est la version dédiée à la falsification explicite du modèle, en s’appuyant sur les observables construites jusqu’à V11.
 
Il se compose de quatre modules :
 
- V12-ABSOLUTE : bornes absolues sur les redshifts internes.  
- V12-ALPHA : bornes sur le champ α(E,n,r).  
- V12-FINE : bornes sur les corrections fines extrêmes.  
- V12-GLOBAL : verdict global de falsification.
 
Le wrapper global est v12falsifier_suite.

V12-ABSOLUTE — Bornes sur les redshifts internes
 
Hypothèse testée : les redshifts internes (V11-GEO, V11-ATOM, V11-CANAL, V11-TOTAL) doivent rester dans des bornes conservatrices pour ne pas être rejetés.
 
Forme opérationnelle :
 
- on récupère les valeurs nominales de V11 :  
  - \(z{\rm geo}\), \(z{\rm int}\), \(z{\rm canal}\), \(z{\rm mod}\)  
- on impose des bornes :
 
  - \(10^{-7} \le z_{\rm geo} \le 2\times10^{-6}\)  
  - \(10^{-7} \le z_{\rm int} \le 10^{-5}\)  
  - \(5\times10^{-7} \le z_{\rm canal} \le 5\times10^{-6}\)  
  - \(10^{-6} \le z_{\rm mod} \le 10^{-5}\)
 
Verdict :
 
- conforme si toutes les valeurs restent dans les bornes,  
- falsifié si au moins une sort franchement de l’intervalle.
 
---
 
V12-ALPHA — Bornes sur α(E,n,r)
 
Hypothèse testée : le champ α(E,n,r) doit rester proche de la valeur de référence et garder une structure cohérente.
 
Forme opérationnelle :
 
- on échantillonne α(E,n,r) sur une grille (E, n, r) héritée de V7/V8/V9,  
- on impose :
 
  - \( |\alpha(E,n,r) - \alpha_{\rm ref}| \le 10^{-8} \) (bande stricte)  
  - \(\partial\alpha/\partial r \le 0\) (pas de renversement de signe)  
  - existence d’une surface de stabilité (variation locale minimale non nulle).
 
Verdict :
 
- conforme si la bande et les dérivées sont respectées,  
- falsifié si α sort de la bande ou si la surface de stabilité disparaît.
 
---
 
V12-FINE — Bornes sur les corrections fines
 
Hypothèse testée : les corrections de niveaux (V8, V9, V10-SPECTRE) doivent rester dans une plage réaliste et garder leur structure.
 
Forme opérationnelle :
 
- on récupère \(\Delta E_{\rm torsion}(Z)\) pour H, He, Fe, Pb, U, Xe…  
- on impose :
 
  - \(10^{-6} \le |\Delta E_{\rm torsion}(Z)| \le 10^{-3}\ \text{eV}\)  
  - monotonicité globale avec Z (Fe, Pb, U plus sensibles que H, He)  
  - Fe doit rester dans une zone stable (pas de saut brutal).
 
Verdict :
 
- conforme si toutes les corrections restent dans la plage et la hiérarchie,  
- falsifié sinon.
 
---
 
V12-GLOBAL — Verdict de falsification
 
Hypothèse testée : le modèle global est rejeté si au moins un bloc V12 est falsifié.
 
Forme opérationnelle :
 
- on agrège les verdicts de :  
  - V12-ABSOLUTE  
  - V12-ALPHA  
  - V12-FINE  
 
Règle :
 
- overall_verdict = supported si tous les blocs sont conformes,  
- overall_verdict = partial si un bloc est limite mais pas hors bornes,  
- overall_verdict = falsified si un bloc est clairement hors bornes.
