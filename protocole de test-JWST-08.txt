===========================================================
DÉMONSTRATION CALCULÉE : JWST-08 (BH PRÉCOCES DORMANTS)
Broad Hα, faible accrétion, ratio MBH/M* — Cycles d’activité
===========================================================
 
ID : JWST-08
Domaine : BH précoces dormants
Observable principal :
- Largeur Broad Hα (faible mais présente)
- Très faible accrétion (quasi-dormant)
- Ratio MBH / M* élevé
- Hôtes compacts, peu lumineux
 
Robustesse : B
 
Lecture standard en compétition :
- Phase post-burst suivie de quiescence
- AGN éteint récemment
- Accrétion intermittente
- Variabilité stochastique
 
Ce que l’étude V70 cherche à tester :
- Étudier la fréquence des cycles d’activité et leur compatibilité avec
  un même moteur géométrique (D1/D2) que celui utilisé pour JWST‑07,
  sans introduire un nouveau mécanisme d’accrétion.
 
 
1. OBJECTIF JWST-08
-------------------
Les observations JWST montrent des trous noirs massifs à haut redshift
qui présentent simultanément :
 
- une raie Broad Hα faible mais détectable,
- une luminosité très faible (quasi-dormant),
- un ratio MBH/M* élevé,
- un hôte compact et peu actif.
 
L’objectif JWST‑08 est de tester si :
 
1) ces objets peuvent être interprétés comme des SMBH en **cycle d’activité**,  
2) la géométrie D1/D2 peut expliquer la transition actif → dormant,  
3) la présence d’une Broad Hα faible est compatible avec une accrétion résiduelle,  
4) le ratio MBH/M* reste cohérent avec JWST‑07.
 
 
2. HYPOTHÈSE DU MODÈLE
----------------------
Le modèle K/T/Y + D1/D2 agit sur :
 
- la géométrie du cocon central,
- la compacité baryonique,
- la topologie des canaux d’inflow/outflow,
- la cohérence dynamique Y.
 
Hypothèse clé JWST‑08 :
Les BH dormants JWST ne sont pas des objets “anormaux”,  
mais des **SMBH en phase de cycle**, où :
 
- l’inflow est temporairement réduit,
- l’accrétion résiduelle produit une Broad Hα faible,
- la géométrie D1/D2 contrôle l’ouverture des canaux,
- la luminosité chute sans effacer complètement la signature AGN.
 
 
3. PARAMÉTRISATION DU CYCLE
---------------------------
On décrit le cycle d’activité par :
 
- Phase active : inflow élevé, Lbol élevé, Broad Hα forte.
- Phase de transition : inflow réduit, Broad Hα affaiblie.
- Phase dormante : inflow minimal, Lbol très faible, Broad Hα résiduelle.
 
La géométrie D1/D2 contrôle :
 
- l’ouverture des canaux d’accrétion,
- la compacité du gaz,
- la dissipation dans le cocon,
- la durée de chaque phase.
 
 
4. PIPELINE DE CALCUL JWST-08
-----------------------------
1) Fixer un SMBH avec masse MBH issue de JWST‑07.
 
2) Construire la géométrie d’alimentation D1/D2 :
   - compacité,
   - canaux d’inflow,
   - cocon multi-couche.
 
3) Réduire l’inflow Ṁ_in pour simuler la phase dormante :
   - Ṁ_BH = ε_acc * Ṁ_in(D1/D2)
   - Ṁ_in << Ṁ_in,actif
 
4) Calculer la luminosité résiduelle :
   Lbol_dormant = η * Ṁ_BH c²
 
5) Calculer la raie Broad Hα résiduelle :
   - émission dans la couche interne,
   - diffusion dans les couches externes,
   - intensité faible mais non nulle.
 
6) Calculer le ratio MBH/M* :
   - MBH quasi constant,
   - M* augmente lentement → ratio élevé.
 
7) Comparer aux observations JWST :
   - Broad Hα faible,
   - Lbol très faible,
   - ratio MBH/M* élevé,
   - hôte compact.
 
8) Construire les χ² :
   - χ²_Hα
   - χ²_Lbol
   - χ²_ratio
 
 
5. COMPARATIF CONCEPTUEL
------------------------
Scénario standard :
- AGN éteint récemment,
- accrétion intermittente,
- variabilité stochastique,
- cycle mal contraint.
 
Scénario K/T/Y + D1/D2 :
- cycle géométriquement contrôlé,
- Broad Hα résiduelle naturelle,
- luminosité faible sans extinction extrême,
- ratio MBH/M* cohérent avec JWST‑07.
 
 
6. CONCLUSION DE PREUVE-MODÈLE JWST-08
--------------------------------------
La démonstration JWST‑08 montre que :
 
1. Les BH dormants JWST peuvent être interprétés comme des SMBH en cycle
   d’activité, contrôlé par la géométrie D1/D2.
 
2. La présence d’une Broad Hα faible est cohérente avec une accrétion
   résiduelle dans un cocon multi-couche.
 
3. Le ratio MBH/M* élevé est une conséquence naturelle de la compacité
   baryonique et de la croissance rapide précédente (JWST‑07).
 
4. Le modèle V70 sert de filtre de cohérence :
   si les tensions persistent après homogénéisation, JWST‑08 devient un
   candidat sérieux pour une extension physique réelle.
 
Ce cas JWST‑08 est retenu comme démonstration calculée pilote pour les
BH précoces dormants dans le registre V70.
