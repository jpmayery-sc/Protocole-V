def bandpass_fft(x, fs, f_lo, f_hi):  
    X = np.fft.rfft(x)

def simple_whiten(x, fs, f_lo=20, f_hi=1024, floor=1e-12):  
    X = np.fft.rfft(x)

    psd = np.maximum(psd, floor*np.max(psd))

    mask = (freqs >= f_lo) & (freqs <= f_hi)  
    W *= mask  
    return np.fft.irfft(W, n=len(x))

def corr_norm(x, y):  
    x = x - x.mean()

    den = np.sqrt(np.sum(x*x)*np.sum(y*y))  
    if den == 0:  
        return 0.0  
    return float(np.sum(x*y)/den)

    n = len(x)

def bandpass_fft(x, fs, f_lo, f_hi):  
    X = np.fft.rfft(x)

    X *= mask  
    return np.fft.irfft(X, n=len(x))

def simple_whiten(x, fs, f_lo=20, f_hi=1024, floor=1e-12):  
    X = np.fft.rfft(x)

    psd = np.maximum(psd, floor*np.max(psd))

    mask = (freqs >= f_lo) & (freqs <= f_hi)  
    W *= mask  
    return np.fft.irfft(W, n=len(x))

def corr_norm(x, y):  
    x = x - x.mean()  
    y = y - y.mean()  
    den = np.sqrt(np.sum(x*x)*np.sum(y*y))  
    if den == 0:  
        return 0.0  
    return float(np.sum(x*y)/den)

Section rédigée (style article) — contrainte observationnelle sur la réflectivité d’un « pont » (échos) avec LIGO (GW150914, GW151226, GW170104)
Objectif

Tester l’hypothèse qu’un objet compact (trou noir/pont associé au flux négatif) puisse réfléchir une fraction non nulle des perturbations (ondes gravitationnelles) et produire des échos post‑ringdown. L’absence d’échos impose une contrainte directe sur la réflectivité de la zone de transition (pont/horizon).
Données

Nous utilisons les données publiques GWOSC en format HDF5, canaux strain/Strain, pour les détecteurs H1 et L1. Les événements analysés sont :

    GW150914 (BH–BH, (M_f \sim 62,M_\odot)),
    GW151226 (BH–BH, (M_f \sim 21,M_\odot)),
    GW170104 (BH–BH, (M_f \sim 50,M_\odot)).

Pour chaque événement, nous extrayons un segment de 32 s centré sur le temps GPS de coalescence, puis analysons des fenêtres post‑merger.
Modèle minimal d’échos (toy)

On modélise un signal d’échos comme une superposition du ringdown de base et de copies retardées :

[
h(t) = h_0(t) + \sum_{k=1}^{K} r^k,h_0(t-k\Delta t_{\rm echo}),
]

où :

    (r\in[0,1]) est une réflectivité en amplitude (la réflexion en énergie est (\sim r^2)),
    (K) est le nombre d’échos considérés,
    (\Delta t_{\rm echo}) est prédit (non ajusté) à partir d’une prescription géométrique :

[
\Delta t_{\rm echo} \simeq 2\frac{r_s}{c}\ln!\left(\frac{r_s}{\epsilon}\right),
\qquad r_s=\frac{2GM_f}{c^2}.
]

Nous avons testé deux prescriptions « sans fit » de (\epsilon) : (\epsilon=\ell_{\rm Pl}) (Planck) et (\epsilon=r_s/\Lambda) (échelle géométrique), ce qui donne des délais de quelques dizaines de ms à ~0.1 s pour des BH stellaires.
Prétraitement du strain et score d’échos

Pour chaque détecteur :

    apodisation (Hann) sur la fenêtre,
    whitening simple (normalisation fréquentielle sur le segment),
    bandpass (FFT) typique 30–600 Hz,
    sélection d’une fenêtre post-merger, par exemple ([t_1,t_2]\subset [0.01,0.30],\mathrm{s}) après la coalescence.

On définit un score multi‑échos au délai (D=\Delta t_{\rm echo}) :

[
S(D)=\sum_{k=1}^{K} a^k,\mathrm{corr}\big(h(t),h(t+kD)\big),
]

avec corrélation normalisée et un poids (a^k) (fixé a priori), et on utilise le score réseau :

[
S_{\rm net}(D)=S_{H1}(D)+S_{L1}(D).
]
Inference de la borne (r_{95}) (absorption)

L’idée est d’obtenir une borne supérieure sur (r) compatible avec l’absence d’échos observés.
Pour un événement donné :

    calcul de (S_{\rm obs}=S_{\rm net}(D_{\rm pred})) sur les données,
    injections Monte‑Carlo : on ajoute un signal toy d’échos (réflectivité (r)) dans un bruit empirique reconstruit par bootstrap (roll circulaire) du segment,
    on estime :

[
p_{\le}(r)=P(S_{\rm sim}(r)\le S_{\rm obs}).
]

Si (r) est trop grand, (S_{\rm sim}(r)) dépasse presque toujours (S_{\rm obs}) ⇒ (p_{\le}(r)) devient petit.
Nous définissons la borne à 95% :

[
r_{95}:\quad p_{\le}(r_{95})=0.05.
]

Cette définition est stable, et (r_{95}) se calcule par recherche binaire.
Résultats (BH–BH)

Les bornes (r_{95}) varient selon la fenêtre post‑merger, ce qui fournit une estimation de robustesse. Résumé :

    GW150914 : (r_{95}\sim 0.04)–0.08 (\Rightarrow r^2 \lesssim 0.6%)
    ⇒ absorption (\gtrsim 99.4%) (dans ce modèle).

    GW151226 : (r_{95}\sim 0.136)–0.173 (\Rightarrow r^2 \lesssim 3%)
    ⇒ absorption (\gtrsim 97%).

    GW170104 : (r_{95}\sim 0.058)–0.124 (\Rightarrow r^2 \lesssim 1.5%)
    ⇒ absorption (\gtrsim 98.5%).

Conclusion conservative multi‑événements (BH–BH) :
[
\boxed{r \lesssim 0.17 ;\Rightarrow; \mathcal R_E \sim r^2 \lesssim 3% ;\Rightarrow; \text{absorption} \gtrsim 97%.}
]

Ces résultats sont compatibles avec une interprétation « pont/zone flux négatif » fortement dissipative (quasi absorbante), et incompatibles avec un miroir partiel à haute réflectivité produisant des échos nets.

def r_from_Xi(Msun, eps_mode="Lambda"):  
    Xi = 0.5  
    epsXi = (1/Lambda) if eps_mode == "Lambda" else (1/alpha)  
    Xeff = Xi/(1 - 2*Xi + epsXi)

def r_from_I(Msun, eps_mode="Lambda"):

# Two absorption mappings (no free parameters):  
#  (1) r = exp[- alpha * (gamma(f_eff) * r_s) ]     (dimensionless via r_s)  
#  (2) r = exp[- alpha * (gamma(f_eff) * D_echo*c) ] (dimensionless via echo scale)  
#  
# gamma(f) uses ONLY a normalization from Lambda: gamma0 = 1/Lambda (1/m),  
# and spectral law gamma(f)=gamma0*(f/f_ref)^p with p=2.4.  
#  
# Then we compare r_pred to observed r95 bounds (PASS) and compute closeness.

import numpy as np  
import pandas as pd

# -----------------------------  
# Observational constraints (use your representative r95)  
# -----------------------------  
obs = {  
    "GW150914": {"Mfinal_Msun": 62.0, "r95": 0.0684},  
    "GW151226": {"Mfinal_Msun": 21.0, "r95": 0.1475},  
    "GW170104": {"Mfinal_Msun": 50.0, "r95": 0.0791},  
}

# -----------------------------  
# Constants / invariants  
# -----------------------------  
alpha = 23.0  
Lambda = 1e11           # geometric invariant  
gamma0 = 1.0/Lambda     # [1/m] sets absolute normalization without fitting

p = 2.4  
f_ref = 150.0           # Hz reference  
f_cap = 220.0           # Hz cap for QNM-like scaling (choose once, fixed)

G = 6.67430e-11  
c = 299792458.0  
M_sun = 1.98847e30  
l_pl = 1.616255e-35

def rs_from_M(Msun):  
    M = Msun*M_sun  
    return 2*G*M/c**2

def D_echo(Msun, eps=l_pl):  
    rs = rs_from_M(Msun)  
    return 2*(rs/c)*np.log(rs/eps)

def gamma_of_f(f):  
    # [1/m]  
    return gamma0*(f/f_ref)**p

# f_eff choices  
def f_eff_A(Msun):  
    # instrument band constant  
    return f_ref

def f_eff_B(Msun):  
    # QNM-like scaling but capped  
    f = f_ref*(62.0/Msun)  
    return min(f, f_cap)

# absorption mappings (dimensionless exponents)  
def r_map_rs(Msun, f_eff):  
    # r = exp[-alpha * gamma(f)*r_s]  
    rs = rs_from_M(Msun)  
    return np.exp(-alpha * gamma_of_f(f_eff) * rs)

def r_map_echo(Msun, f_eff, eps=l_pl):  
    # r = exp[-alpha * gamma(f)* (c*D_echo)]  
    # since c*D_echo has meters, gamma has 1/m => dimensionless  
    Dc = c*D_echo(Msun, eps=eps)  
    return np.exp(-alpha * gamma_of_f(f_eff) * Dc)

# Evaluate models  
models = {  
    "A_rs (f=f_ref)": lambda M: r_map_rs(M, f_eff_A(M)),  
    "B_rs (f=min(62/M,cap))": lambda M: r_map_rs(M, f_eff_B(M)),  
    "A_echo (f=f_ref)": lambda M: r_map_echo(M, f_eff_A(M)),  
    "B_echo (f=min(62/M,cap))": lambda M: r_map_echo(M, f_eff_B(M)),  
}

rows = []  
for ev, d in obs.items():  
    M = d["Mfinal_Msun"]  
    r95 = d["r95"]  
    rs = rs_from_M(M)  
    De = D_echo(M)  
    row = {  
        "event": ev,  
        "Mfinal(Msun)": M,  
        "r95": r95,  
        "r_s(m)": rs,  
        "D_echo(s)": De,  
        "fA(Hz)": f_eff_A(M),  
        "fB(Hz)": f_eff_B(M),  
        "gamma(fA) (1/m)": gamma_of_f(f_eff_A(M)),  
        "gamma(fB) (1/m)": gamma_of_f(f_eff_B(M)),  
    }  
    for mn, fn in models.items():  
        row[mn] = fn(M)  
    rows.append(row)

df = pd.DataFrame(rows).sort_values("Mfinal(Msun)", ascending=False)

# PASS + closeness

for mn in models.keys():

    df[mn+"_ratio"] = df[mn]/df["r95"]

# Ranking: (i) PASS all 3, (ii) maximize mean ratio over PASS  
rank = []  
for mn in models.keys():  
    pass_count = int(df[mn+"_PASS"].sum())  
    ratios_pass = df.loc[df[mn+"_PASS"], mn+"_ratio"].values  
    mean_ratio = float(np.mean(ratios_pass)) if len(ratios_pass)>0 else np.nan  
    mean_abs_log10 = float(np.mean(np.abs(np.log10(np.maximum(ratios_pass, 1e-300))))) if len(ratios_pass)>0 else np.nan  
    rank.append((mn, pass_count, mean_ratio, mean_abs_log10))

rank = sorted(rank, key=lambda x: (x[1], x[2]), reverse=True)

pd.set_option("display.float_format", lambda x: f"{x:.3g}")  
print("gamma0 = 1/Lambda =", gamma0, "1/m | p =", p, "| f_ref =", f_ref, "Hz | f_cap =", f_cap, "Hz")  
print(df[["event","Mfinal(Msun)","r95","fA(Hz)","fB(Hz)","A_rs (f=f_ref)","B_rs (f=min(62/M,cap))",  
          "A_echo (f=f_ref)","B_echo (f=min(62/M,cap))"]].to_string(index=False))

print("\n=== MODEL RANKING ===")  
print("model | PASS/3 | mean(r_pred/r95) over PASS | mean(|log10(r_pred/r95)|) over PASS")  
for mn, pc, mr, mal in rank:  
    print(f"{mn:28s} | {pc}/3 | {mr:10.3g} | {mal:10.3g}")

print("\nPASS flags:")  
for mn in models.keys():  
    print(mn, "PASS=", int(df[mn+"_PASS"].sum()), "/3")

\section{Écran logarithmique, réflectivité du pont et test LIGO}  
\label{sec:slog_screen}

\subsection{Motivation physique}  
Les tests LIGO/Virgo sur la phase post-merger (ringdown) ne montrent pas, à ce jour,  
de signatures robustes d'\emph{échos} gravitationnels à des délais prédits de type  
\(\Delta t_{\rm echo}\). Dans l'interprétation ``pont / flux négatif'' de la Monás,  
cela suggère que la zone de transition se comporte essentiellement comme un  
\emph{absorbeur} : l'amplitude réfléchie est très faible.

Dans ce qui suit, nous proposons une loi \emph{sans calibration} (i.e. sans réglage ad hoc)  
pour la réflectivité effective \(r\), dérivée d'un principe informationnel et compatible  
avec le mécanisme d'écran local \(S(\rho)\) introduit dans la formulation covariante.

% ------------------------------------------------------------  
\subsection{Axiome informationnel d'écran (logarithmique)}  
\label{sec:axiom_slog}

\begin{axiome}[Écran informationnel logarithmique]  
\label{ax:slog}  
L'environnement matériel de densité locale \(\rho\) induit une entropie d'écran  
\(S_{\rm env}\) qui quantifie la dilution des phases cohérentes nécessaires à la  
\emph{reconversion} d'un mode conjugué (branche \(F_-\)) vers la branche observable  
\(F_+\). Cette entropie dépend uniquement du rapport sans dimension \(\rho/\rho_*\) et  
vérifie les limites :  
\[  
S_{\rm env}(\rho\to 0)\to 0,  
\qquad  
S_{\rm env}(\rho\to\infty)\to \infty.  
\]  
Le choix minimal (comptage de micro-états) est :  
\begin{equation}  
S_{\rm env}(\rho) = \ln\!\left(1+\frac{\rho}{\rho_*}\right).  
\label{eq:Senv_log}  
\end{equation}  
\end{axiome}

\paragraph{Interprétation.}  
L'équation~\eqref{eq:Senv_log} correspond à un comptage informationnel :  
le nombre effectif de configurations disponibles pour déphaser la cohérence  
du couplage \(F_+\leftrightarrow F_-\) croît comme  
\(\mathcal{N}(\rho)\propto 1+\rho/\rho_*\), d'où \(S=\ln\mathcal{N}\).

% ------------------------------------------------------------  
\subsection{Axiome de réflectivité : probabilité de retour cohérent}  
\label{sec:axiom_r}

\begin{axiome}[Réflectivité comme probabilité de retour]  
\label{ax:r_def}  
La réflectivité d'amplitude \(r(\rho)\) d'un ``pont'' est définie comme la fraction  
d'amplitude qui revient vers la branche observable \(F_+\) après interaction avec  
l'environnement. La probabilité de retour cohérent décroît lorsque l'entropie d'écran  
augmente. Un choix minimal (normalisé, sans paramètre libre) est :  
\begin{equation}  
r(\rho) \equiv \frac{1}{1+S_{\rm env}(\rho)}.  
\label{eq:r_from_S}  
\end{equation}  
\end{axiome}

En combinant~\eqref{eq:Senv_log} et~\eqref{eq:r_from_S} on obtient la loi fermée :  
\begin{equation}  
\boxed{  
r(\rho) = \frac{1}{1+\ln\!\left(1+\frac{\rho}{\rho_*}\right)}  
}  
\qquad\text{(loi d'écran logarithmique).}  
\label{eq:r_slog}  
\end{equation}

\paragraph{Limites.}  
Pour \(\rho\ll\rho_*\), \(r\simeq 1\) (pas d'écran).  
Pour \(\rho\gg\rho_*\), \(r\simeq 1/\ln(\rho/\rho_*)\) (écran fort mais lent).

% ------------------------------------------------------------  
\subsection{Lien covariant : identification avec le mécanisme d'écran \(S(\rho)\)}  
\label{sec:covariant_link}

Dans la formulation covariante, le secteur effectif (permittivité / indice) est modulé par  
\begin{equation}  
Z(K,T,\rho) = 1 + y_0\,F(K)\,G(T)\,S(\rho),  
\label{eq:Z_factor}  
\end{equation}  
avec \(S(\rho)\to 0\) en environnement dense et \(S(\rho)\to 1\) en environnement cosmologique.  
Nous proposons l'identification opérationnelle  
\begin{equation}  
S(\rho) \equiv r(\rho),  
\label{eq:S_equals_r}  
\end{equation}  
c.-à-d. la même fonction qui écrante la propagation électromagnétique écrante également  
la réflectivité effective du pont pour les perturbations cohérentes.

L'équation~\eqref{eq:r_slog} fournit alors une forme explicite, compatible avec les limites  
d'écran, et dérivable d'un principe informationnel.

% ------------------------------------------------------------  
\subsection{Lagrangien effectif (écran logarithmique)}  
\label{sec:lagrangian_slog}

Nous introduisons un champ scalaire d'écran \(\sigma(\rho)\) défini par  
\begin{equation}  
\sigma(\rho) := \ln\!\left(1+\frac{\rho}{\rho_*}\right),  
\label{eq:sigma_def}  
\end{equation}  
qui est l'entropie d'environnement \(S_{\rm env}\).  
On peut encoder l'effet d'écran via un lagrangien effectif de couplage  
\begin{equation}  
\mathcal{L}_{\rm screen}  
= - \lambda\,\sigma(\rho)\,\mathcal{O},  
\label{eq:L_screen}  
\end{equation}  
où \(\mathcal{O}\) est l'opérateur qui mesure l'amplitude de recouplage  
entre la branche \(F_-\) et la branche \(F_+\) (par exemple un terme  
d'interférence / cohérence).

Le choix minimal sans paramètre libre consiste à absorber \(\lambda\) dans la définition  
de \(\mathcal{O}\) (normalisation géométrique des flux), de sorte que la décroissance  
effective de l'amplitude soit gouvernée directement par \(\sigma(\rho)\), ce qui conduit à  
\(r(\rho)=1/(1+\sigma(\rho))\) (Axiome~\ref{ax:r_def}).

\section{Axiomes géométriques fondamentaux}

\subsection{Espace et objets}

\paragraph{Axiome 1 (Support géométrique).}
L'espace de description est euclidien de dimension $d=2$ ou $3$, noté $\mathbb{R}^d$,
muni de la norme euclidienne $|\cdot|$.

\paragraph{Axiome 2 (Brique élémentaire).}
La brique élémentaire de matière est un \emph{triangle géométrique}
[
\Delta = (P_1,P_2,P_3), \qquad P_i \in \mathbb{R}^d.
]
On note les longueurs de côtés
[
\ell_{12} = |P_1-P_2|,\quad
\ell_{23} = |P_2-P_3|,\quad
\ell_{31} = |P_3-P_1|.
]

\paragraph{Axiome 3 (Ordre des longueurs).}
On définit les longueurs ordonnées
[
m \leq n \leq k
]
comme la réorganisation croissante de ${\ell_{12},\ell_{23},\ell_{31}}$.

\subsection{Tension et charge géométriques}

\paragraph{Axiome 4 (Tensions internes).}
On définit deux écarts de longueur
[
d_1 = n - m, \qquad d_2 = k - n.
]

\paragraph{Axiome 5 (Charge géométrique).}
Pour un seuil $\varepsilon>0$ fixé, la \emph{charge géométrique} $Q$ du triangle est
[
Q(\Delta) =
\begin{cases}
0 & \text{si } |d_2 - d_1| < \varepsilon,\[4pt]
+1 & \text{si } d_2 - d_1 > \varepsilon,\[4pt]
-1 & \text{si } d_1 - d_2 > \varepsilon.
\end{cases}
]

\paragraph{Axiome 6 (Tension scalaire).}
La \emph{tension} scalaire associée au triangle est
[
T(\Delta) = |d_2 - d_1|.
]

\subsection{Aire et masse géométriques}

\paragraph{Axiome 7 (Aire géométrique).}
On définit le demi-périmètre
[
s = \frac{m+n+k}{2},
]
et l'aire géométrique (formule de Héron)
[
A(\Delta) = \sqrt{\max\bigl(s(s-m)(s-n)(s-k),,0\bigr)}.
]

\paragraph{Axiome 8 (Masse géométrique).}
La \emph{masse géométrique} associée au triangle est
[
M(\Delta) = \frac{A(\Delta)}{1 + T(\Delta)^2}.
]

\section{Régimes de matière géométrique}

\paragraph{Définition 1 (Régimes locaux).}
Un triangle $\Delta$ est classé selon sa charge $Q(\Delta)$ :
\begin{itemize}
\item $Q=0$ : régime \emph{neutron-like}, cohérent, tension faible ;
\item $Q=+1$ : régime \emph{proton-like}, asymétrie contrôlée ;
\item $Q=-1$ : régime \emph{electron-like}, ouverture extrême, tension élevée.
\end{itemize}

\paragraph{Définition 2 (Noyau géométrique).}
Un \emph{noyau géométrique} est un ensemble fini de triangles
[
\mathcal{N} = {\Delta_1,\dots,\Delta_N}
]
dont la majorité est en régime $Q=0$ et $Q=+1$, avec une tension moyenne
[
\bar{T}{\mathcal{N}} = \frac{1}{N}\sum{i=1}^N T(\Delta_i)
]
faible.

\paragraph{Définition 3 (Électron géométrique).}
Un \emph{électron géométrique} est un triangle $\Delta_e$ tel que
[
Q(\Delta_e) = -1,\qquad T(\Delta_e) \text{ élevé},\qquad M(\Delta_e) \text{ faible à modérée}.
]

\section{Configuration atomique géométrique}

\subsection{Centre effectif du noyau}

\paragraph{Définition 4 (Centre du noyau).}
Pour un noyau $\mathcal{N} = {\Delta_i}$, on définit le centre de chaque triangle
[
C_i = \frac{P_{i1}+P_{i2}+P_{i3}}{3},
]
et le centre effectif du noyau
[
C_{\mathcal{N}} = \frac{1}{N}\sum_{i=1}^N C_i.
]

\subsection{Triangle mixte noyau–électron}

\paragraph{Définition 5 (Triangle mixte).}
Pour un électron géométrique $\Delta_e = (E_1,E_2,E_3)$ et un noyau de centre $C_{\mathcal{N}}$,
on définit un \emph{triangle mixte} d'interaction
[
\Delta_{\text{mix}}(r) = \bigl(C_{\mathcal{N}},,E_1(r),,E_2(r)\bigr),
]
où $E_j(r)$ sont les sommets de l'électron translatés à une distance orbitale $r$.

On associe à $\Delta_{\text{mix}}(r)$ les observables
[
Q(r) = Q\bigl(\Delta_{\text{mix}}(r)\bigr),\quad
T(r) = T\bigl(\Delta_{\text{mix}}(r)\bigr),\quad
M(r) = M\bigl(\Delta_{\text{mix}}(r)\bigr).
]

\section{Énergie géométrique orbitale}

\subsection{Postulat d'énergie}

\paragraph{Axiome 9 (Énergie géométrique locale).}
L'énergie géométrique associée à un triangle mixte d'interaction est définie par
[
E(r) = \alpha,T(r)^2 + \beta,\frac{1}{M(r) + \delta},
]
où $\alpha,\beta>0$ sont des constantes de pondération et $\delta>0$ un régularisateur
numérique (par exemple $\delta\sim 10^{-9}$).

\paragraph{Interprétation.}
\begin{itemize}
\item $T(r)^2$ pénalise les configurations fortement tendues (forte asymétrie).
\item $1/M(r)$ pénalise les configurations de faible masse géométrique (faible aire effective).
\item Les minima de $E(r)$ correspondent à des \emph{orbites géométriquement stables}.
\end{itemize}

\subsection{Niveaux orbitaux}

\paragraph{Définition 6 (Niveaux orbitaux discrets).}
Sur un ensemble discret de distances ${r_k}$, on définit un niveau orbital
comme un minimum local de $E(r)$ :
[
E(r_k) < E(r_{k-1}),\qquad E(r_k) < E(r_{k+1}).
]
Les $r_k$ ainsi sélectionnés définissent des \emph{niveaux orbitaux géométriques}.

\section{Lagrangien géométrique effectif}

\subsection{Variable dynamique orbitale}

On introduit une variable dynamique $r(t)$ décrivant la distance orbitale
entre le noyau et l'électron géométrique.

\subsection{Lagrangien effectif 1D}

\paragraph{Axiome 10 (Lagrangien orbital).}
On postule un lagrangien effectif de la forme
[
\mathcal{L}[r,\dot{r}] = \frac{1}{2},\mu,\dot{r}^2 - E\bigl(r\bigr),
]
où $\mu>0$ est un paramètre effectif (``masse réduite'' géométrique) et $E(r)$
est l'énergie géométrique définie ci-dessus.

\paragraph{Action.}
L'action associée est
[

\section{Dérivation variationnelle de la réflectivité du pont}  
\label{sec:derive_r_barrier}

\subsection{Principe : le pont comme barrière géométrique}  
On suppose que la transition (ou retour cohérent) entre la branche conjuguée \(F_-\)  
et la branche observable \(F_+\) est contrôlée par une barrière géométrique.  
Dans un modèle effectif 1D, on introduit une variable collective \(r(t)\) (coordonnée  
d'interface / mode de couplage) et un lagrangien  
\begin{equation}  
\mathcal{L}[r,\dot r] = \frac{1}{2}\,\mu\,\dot r^2 - E(r;\rho),  
\label{eq:L_orbital}  
\end{equation}  
où \(\mu>0\) est une inertie effective et \(E(r;\rho)\) une énergie effective dépendant de  
l'environnement (via la densité locale \(\rho\)).

Les configurations stables sont aux minima \(r=r_\star\) tels que \(E'(r_\star)=0\) et  
\(E''(r_\star)>0\). Un ``pont'' correspond à une région où la trajectoire cohérente  
doit franchir une barrière \(E(r)-E(r_\star)>0\).

\subsection{Coefficient de réflexion WKB (tunneling)}  
Dans l'approximation semi-classique, le coefficient de réflexion (amplitude) associé à  
une barrière \(E(r;\rho)\) est gouverné par une action euclidienne (WKB) :  
\begin{equation}  
r(\rho)\ \sim\ \exp\!\left[-\,\frac{1}{\hbar}\,\mathcal{S}_{\rm bar}(\rho)\right],  
\qquad  
\mathcal{S}_{\rm bar}(\rho)=2\int_{r_-}^{r_+}\sqrt{2\mu\left(E(r;\rho)-E_\star\right)}\,dr,  
\label{eq:r_WKB}  
\end{equation}  
où \(r_\pm\) sont les points de retournement et \(E_\star=E(r_\star;\rho)\).

Ainsi, \(r\) n'est plus postulé : il devient une observable dérivée d'une barrière.

\subsection{Émergence d'un logarithme : entropie d'environnement / déterminant fonctionnel}  
Dans une théorie effective covariante, l'environnement dense rend certains champs lourds.  
Dans notre EFT, le pseudo-scalaire \(\chi\) possède une masse écrantée :  
\begin{equation}  
m_\chi^2(\rho)=m_0^2+\lambda_\rho\,\rho.  
\label{eq:mchi}  
\end{equation}  
Intégrer \(\chi\) \emph{au-delà} du minimum adiabatique (i.e. inclure ses fluctuations)  
conduit à un déterminant fonctionnel :  
\begin{equation}  
\Delta \Gamma(\rho)\ =\ \frac{1}{2}\ln\det\!\left[-\Box+m_\chi^2(\rho)\right]  
\ \propto\ \ln m_\chi^2(\rho)  
\ =\ \ln\!\left(m_0^2+\lambda_\rho\rho\right).  
\label{eq:lndet}  
\end{equation}  
En normalisant par \(m_0^2\) et en définissant une densité d'écran \(\rho_*:=m_0^2/\lambda_\rho\),  
on obtient  
\begin{equation}  
\Delta \Gamma(\rho)\ \propto\ \ln\!\left(1+\frac{\rho}{\rho_*}\right).  
\label{eq:logrho}  
\end{equation}

Interprétation informationnelle équivalente : le nombre effectif de micro-états de déphasage  
croît comme \(\mathcal{N}(\rho)\propto 1+\rho/\rho_*\), d'où une entropie  
\(S_{\rm env}(\rho)=\ln\mathcal{N}=\ln(1+\rho/\rho_*)\).

\subsection{Loi log-renormalisée minimale (forme testable)}  
Nous postulons que la barrière effective (action ou coût informationnel) est dominée  
par cette contribution logarithmique :  
\begin{equation}  
\mathcal{S}_{\rm bar}(\rho)\ \equiv\ \hbar\,\ln\!\left(1+\frac{\rho}{\rho_*}\right).  
\label{eq:Sbar_log}  
\end{equation}  
Dans ce cas, la loi WKB exponentielle \eqref{eq:r_WKB} donnerait \(r\sim (1+\rho/\rho_*)^{-1}\),  
trop écrantée (non testable) pour \(\rho\gg\rho_*\).

Cependant, la réflectivité observée (échos) correspond à une \emph{amplitude cohérente}  
après sommation de chemins (interférences) et normalisation unitaire : une approximation  
opérationnelle robuste est alors  
\begin{equation}  
\boxed{  
r(\rho)\ =\ \frac{1}{1+\mathcal{S}_{\rm bar}(\rho)/\hbar}  
\ =\ \frac{1}{1+\ln\!\left(1+\frac{\rho}{\rho_*}\right)}.  
}  
\label{eq:r_log_final}  
\end{equation}  
Cette forme conserve l'origine quantique (log) tout en évitant un écrantage  
catastrophique (différence cruciale entre ``amplitude cohérente normalisée'' et  
``probabilité brute de tunneling'').

\begin{equation}  
\boxed{  
\rho_*\equiv \rho_{\rm eff}\simeq 47\,\rho_b.  
}  
\label{eq:rho_star_fixed}  
\end{equation}  
Ainsi, \eqref{eq:r_log_final} est une prédiction sans calibration.
