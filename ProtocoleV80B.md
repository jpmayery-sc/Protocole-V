# V80B — TEST LITHIUM AVEC $\varepsilon_{best}$

## Objectif
Tester le point V80 au lieu de le rescanner : on fixe $\varepsilon$ à la valeur physique retenue et on vérifie directement si le lithium est corrigé sans perdre D/H ni $Y_p$.

## Hypothèses
- $\varepsilon = \varepsilon_{best} = -0.0069$
- $\delta_{EM} = -0.0069$
- les autres paramètres cosmologiques restent standards
- le calcul BBN utilise le proxy jouet déjà employé par V80

## Procédure
1. Fixer $\varepsilon = -0.0069$.
2. Calculer les abondances primordiales : D/H, $Y_p$, Li-7/H, Be-7/H.
3. Comparer aux valeurs observationnelles codées dans le proxy BBN.
4. Vérifier que D/H et $Y_p$ restent compatibles.
5. Vérifier si Li-7 est seulement réduit ou réellement ramené au bon niveau.

## Références numériques du proxy
- D/H_obs = $2.527\times 10^{-5}$
- $Y_{p,obs} = 0.2465$
- Li-7/H_obs = $1.58\times 10^{-10}$

## Résultat V80B
Le calcul à $\delta_{EM} = -0.0069$ donne :
- D/H = $2.5299\times 10^{-5}$
- $Y_p = 0.24674$
- Li-7/H = $1.5665\times 10^{-10}$
- Be-7/H = $1.3292\times 10^{-10}$

Z-scores associés :
- $z_D = 0.0961$
- $z_Y = 0.0253$
- $z_{Li} = 0.0437$

Conclusion :
- D/H passe largement.
- $Y_p$ passe largement.
- Li-7 est réellement corrigé dans ce modèle jouet, au voisinage direct de l’observation centrale.

## Verdict
V80B confirme que le point $\varepsilon_{best}$ ne soulève pas seulement D/H et $Y_p$, mais place aussi Li-7 dans la bonne fenêtre numérique.

## Transition
Ce test sert de verrou BBN avant toute nouvelle extension sur le plan gravitationnel ou cosmologique.
