V11-GEO — Redshift géométrique D2
 
Hypothèse testée : la torsion D2 et le déficit angulaire induisent un décalage de phase accumulé qui se lit comme un redshift géométrique.
 
Forme opérationnelle :
 
- phase accumulée :  
  \(\Delta\phi = K\phi\,\alpha\left(\dfrac{\tau}{\tau{\rm crit}}\right)^2 L\) (hérité de V6-D2)  
- redshift géométrique :  
  \[
  z{\rm geo} = \frac{\Delta\phi{\rm env} - \Delta\phi_{\rm ref}}{2\pi}
  \]
 
Cas test principal : raie H‑alpha (transition 3→2).
 
Résultats runtime typiques (H‑alpha) :
 
- \(\Delta\phi_{\rm ref} \approx 3.1\times 10^{-3}\)  
- \(\delta\Delta\phi \sim 10^{-6}\)  
- \(z_{\rm geo} \sim 4\times 10^{-7}\)
 
Verdict : conforme (effet petit, non nul, signe cohérent, croissance avec la torsion).
 
---
 
V11-ATOM — Redshift atomique interne
 
Hypothèse testée : les corrections de niveaux dues à la torsion D2 et à la porte alpha induisent un redshift interne des raies atomiques.
 
Forme opérationnelle :
 
- correction de niveau (héritée de V8/V9/V10-SPECTRE) :  
  \(\Delta E_{\rm torsion}(Z)\)  
- redshift interne pour une transition donnée :  
  \[
  z{\rm int} = \frac{\Delta E{\rm torsion,\,env} - \Delta E{\rm torsion,\,ref}}{E{\rm transition}}
  \]
 
Cas test principal : H‑alpha.
 
Résultats runtime typiques :
 
- \(\Delta E_{\rm torsion}(H) \sim 4\times 10^{-5}\ \text{eV}\)  
- variation environnementale \(\delta(\Delta E_{\rm torsion}) \sim 10^{-6}\ \text{eV}\)  
- \(E_{\rm H\alpha} \approx 1.89\ \text{eV}\)  
- \(z_{\rm int} \sim 5\times 10^{-7}\)
 
Verdict : conforme (amplitude dans la bande \(10^{-6}\)–\(10^{-3}\), plus forte pour Z lourds, structure monotone).
 
---
 
V11-CANAL — Redshift du canal électronique
 
Hypothèse testée : la variation de la réponse électronique \(\kappa(n)\) se traduit en un redshift effectif.
 
Base héritée de V6-e / V7-ELEC :
 
- \(\kappa(n) = A\,n^{-p}\), avec \(p \approx 4.95\).
 
Forme opérationnelle :
 
- variation relative de canal :  
  \[
  z_{\rm canal} \approx \frac{\delta\kappa}{\kappa}
  \]
 
Cas test : variation de régime (torsion, environnement) sur des transitions typiques (H, Fe, Pb).
 
Résultats runtime typiques :
 
- \(\delta\kappa/\kappa \sim 10^{-6}\)–\(10^{-5}\)  
- \(z_{\rm canal} \sim 10^{-6}\)
 
Verdict : conforme (effet petit, monotone, sans divergence).
 
---
 
V11-TOTAL — Synthèse du redshift
 
Hypothèse testée : le redshift total prédit par le modèle est la somme cohérente des trois contributions internes.
 
Forme opérationnelle :
 
\[
z{\rm mod} = z{\rm geo} + z{\rm int} + z{\rm canal}

- \(z_{\rm geo} \sim 4\times 10^{-7}\)

- \(z_{\rm canal} \sim 10^{-6}\)  
- \(z_{\rm mod} \sim 2\times 10^{-6}\)
 
Verdict : conforme (effet total petit, structuré, dans une plage potentiellement mesurable).
